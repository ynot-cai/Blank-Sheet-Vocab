## 一、数据与存储

- 保留数据层：一个单词有哪些属性、单词存储位置、数据同步功能。
- 数据同步：可选的多端云同步（同步码 + 服务端只存 hash），另有 JSON 导出/导入与本地文件夹备份作为不依赖云端的兜底。
- （2026-10-28）调整已保存的单词数据格式，使其成为**可直接导入的存档文件**；缺失字段按合理默认值补充。

## 二、录入

- 支持直接粘贴文本或输入内容，支持的文件类型与此前一致；同样支持短语输入。
- AI 分类义项功能：
  1. 补全单词或短语的中文意思；
  2. 将多个中文意思按义项分类，意思相近的归为一类，并为每一类选出代表义项；不同词性视为不同含义；
  3. 为每一个义项记录例句，例句需从牛津字典中查找；若未找到，则填写“暂无”。
- 每一次录入都需要选择“单词来源”和“背诵优先级”（p1 至 p5）。
- “单词来源”需支持“历史记录”功能；若用户未选择来源，则默认使用“默认”来源。
- AI 整理完义项后，提供可选操作：是否覆盖来源名称（默认开启）、是否覆盖优先级（默认开启）、是否覆盖为“未背诵”（默认关闭）。
- 删除“不入库”功能；保留“修改义项”功能；保留“重新 AI 整理”功能；删除“已有词库整理”入口。
- 注意：“输入中文意思”的判分交给 AI 完成，因此义项划分的严谨程度要求可以降低。

## 三、单词列表

### 3.1 两个视图

- 页面上方有切换按钮，可在「**白纸**」与「**单词**」两个视图之间切换；默认打开「白纸」。
- （2026-10-28）「卡片」界面移除单词卡浏览功能，改名为「白纸」，**仅用于浏览白纸存档**。
  搜索、收藏、筛选、排序等功能同样针对**白纸存档**生效。
- 「单词」视图保留原有的搜索、筛选、排序、批量编辑、收藏等功能，不因白纸视图而删除。

### 3.2 白纸视图（浏览白纸存档）

- 只列白纸存档，不出现单词表、不分页、没有单词批量条。
- 工具栏：搜索（存档名称**或存档里出现过的单词**）、状态（全部 / 进行中 / 已背完）、只看收藏、
  排序（最近改动 / 创建时间 / 名称 / 词数）+ 升降序、结果计数、重置筛选。
- 每张存档卡片：名称、状态 · 词数、收藏星标、查看、重命名。

### 3.3 单词视图

- 表格展示词条：勾选、单词（含音标与收藏星标）、义项、来源、词级优先级、①拼写标记 ②未通过 ③复习次数
  ④距上次复习 ⑤距背诵 ⑥优先度、状态、操作（详情 / 斩 / 更多）。
- 筛选与排序：搜索、状态、来源、只看需拼写、只看收藏、含已斩、未通过次数 ≥、复习优先度 ≥、
  词级优先级、排序 + 升降序。
- 批量：批量斩 / 复活 / 设优先级 / 标记或取消拼写 / 收藏或取消收藏 / 设为未背 / 删除，支持跨页全选。
- 行内「更多」与批量条里都有「AI 重新整理义项」。

## 四、白纸界面（背诵）

- 单词随机出现。
- 按钮：
  - 保存退出：保存当前数据并退出。
  - 删除这张纸：删除已保存的数据；点击后弹确认框，确认后回主界面。
  - 下一个：弹出下一个单词；若下一个词的优先级为 0，点击时提示“没有单词了”然后无事发生。
  - 再次记忆：开始一轮**考核**（见第九节）。
  - 背完了：常态亮起；点击弹“命名白纸”弹窗；未命名直接确认则记为日期“YYYY-MM-DD”；
    确认后该白纸存档清空“临时优先级表”，永久储存。
- 单词周边元素：
  - 最后一个出现的单词自动显示中文意思；
  - 平时默认只显示英文，右上角显示浅色义项个数标识；
  - 点击英文切换中文意思显示；中文只显示义项代表，附带词性（单个单词时）；
  - 点击中文出现单词卡。
- 统计信息：手机版在中间正下方、宽屏版在按钮上方，灰字小字显示“当前：xx词，平均复习：xx遍”。
- 单词分布：均匀、随机、无序；单词之间、单词与按钮之间不重叠；单词与单词卡不出屏；
  适配不同屏幕尺寸，小屏不得因固定边距只剩一列；按钮大小固定；单词与按钮、边框的最小间距要足够小。
- 文字边界：英文与中文都不得溢出画面边界。
- 保存并退出后再进入：单词位置与“已经出现”状态保持不变，不需要重复点“下一个”回到原位。
- 背诵期间修改中文意思要立即更新显示。

## 五、单词卡

- 出现位置：正中弹窗（不是挂页面底部、需要滚动的扩展页）。
- 排版自上而下：英文（大黑粗）＋中文（仅义项代表）→ 音标＋发音按钮 → 例句（最多两行，超过给“查看全部”）
  → 按钮区：编辑/保存、AI 整理义项、拼写、仅拼写、斩，水平并排。
- 右上角有“X”关闭按钮：与单词同一行、位于该行**最右端**（2026-10-21 要求“移至右上角、与单词平行”；
  早期“位于最左端”的表述作废）。
- 编辑态：英文变可改文本框；中文显示为“词性，义项代表 + 其他近义词（较灰）”；
  左键改文字、右键菜单只有单一“删除”、左键指针拖动调整顺序、支持新增中文意思；
  原“编辑”变“保存”，点击保存修改。
- 拼写 / 仅拼写：均为**真标记**（不是空壳）：
  - 拼写：该词被选中考核时额外加一次拼写考察；
  - 仅拼写：进入「拼写强化」的标签，标记时自动把单词状态改为“已背”，并立即从白纸上消失。
- 斩：与原来相同，唯一修改点是点击后的绿色通知改为**右上角**弹出。

## 六、单词分布与布点

- 单词在界面中的分布尽量均匀、随机、无序；单词与单词、单词与按钮不得重叠；单词与单词卡不出屏。
- 适配不同尺寸屏幕：小屏不得因边距固定而只能出现一列；最小间距要足够小。
- 按钮大小固定，不随内容或屏幕变化。
- 文字（含中文）必须在画面边界内完整显示。

## 七、主界面与全局样式

- 视觉恢复为归档旧版风格；未明确说明的参数（颜色、间距、字号、圆角、阴影等）一律以旧版归档为准。
- 主界面底色：把旧版“较深的白色”整体调浅一档，保持同色系。
- 底部区域：比上方白条更宽的白条，居中两行——第一行“白纸单词 版本 关于数据”（“关于数据”可点），第二行“by Tony-Cai”。
- 取消主界面中的蓝框样式。
- 统计：项目与旧版一致，视觉改为旧版风格，并在统计文字前加“当前词库：”。
- 仅在主界面、上方白条内、标题左侧显示“用白纸背单词——个人自用的背单词工具”，不加粗、颜色比标题浅。
- 总体风格与录入界面一致；白纸按钮与主界面按钮同一套视觉（蓝框、白底、黑字、等宽等高、
  字号顺序：首页按钮字号 > 单词字号 = 白纸按钮字号）。
- 标题栏：标题在左、说明文字在后；说明文字只出现在主界面；所有有上方白条的页面点击标题回主界面；
  title 区域不得呈现按钮视觉样式（无按下态、高亮、动画反馈、按钮边框）。
- 弹窗 / 独立界面不许做成拼接在下方、可滚轮访问的页面（详见《开发规则》第六节）。

## 八、背诵选择页面与白纸存档

- 点击“背诵”进入“背诵选择页面”，视觉风格与“录入”“设置”一致。
- 四种方式创建临时优先级表，白纸按优先级从高到低选词：
  1. 默认优先级：临时优先级 = 背诵优先级；
  2. 按来源分类：选中来源的词 = 1 + 背诵优先级，其余 0；
  3. 从单词列表选取：折叠栏里的列表支持翻页、筛选、排序、勾选、批量勾选；勾中的词 = 1 + 背诵优先级，其余 0；
  4. AI 智能勾选：用户口述条件发给 AI，跳转确认界面；确认界面支持多轮对话，且**每次提示词包含全部上下文**。
- 相同优先级按首字母顺序。
- 存档 = 临时优先级表 + 分布种子 + 已出现单词名单。
- 存档操作：删除纸张 = 删除存档；保存并退出 = 记录存档（并上传相关考核数据）。
- 页面排版：
  - 选取单词态：左栏“选取单词（亮起）｜继续背诵”，右栏选项区，底部“记录成绩 + 开始背诵”；
  - 继续背诵态：左栏“继续背诵（亮起）”，右栏存档列表，底部“记录成绩（不可用）+ 开始背诵”。
- “记录成绩”勾选框：勾选后该白纸不再记录任何考核信息。
- 视觉：自主优化（添加线、改变框），不得添加有实质信息的文本，风格统一。

## 九、考核（记忆过程）

- 主体流程沿用旧版，评分系统全新设计；提到与未提到的功能、视觉细节都要与旧版一致（除明确改动处）。
- 触发（两种）：点数次“下一个”后自动开始一轮；点“再次记忆”主动开始。
- 界面：独立整页（纯白、中央英文）、单词下方小喇叭（点一次朗读一遍）、按义项个数给输入框、
  提交后出答案卡；英译中结束后进入拼写考察，与旧版相同。
- 选取逻辑：每次个数固定（可调），总数不足则全选；优先“记忆次数”低的词（记忆次数存入白纸存档），
  并列随机；标记“拼写”且被选中的词额外加一次拼写考察；标记“仅拼写”或“斩”的词立即从纸上消失；
  分数低于固定值（可调）且未被抽到的词无视记忆次数强制加考。
- 评分：英译中把答案交给 AI，参考词表记录的意思按准确全面程度打分（满分 5）；拼写考核同旧版。
- 记录：每个词一轮结束后把考核分数与考核次数直接写库。
- 设置里的「考核评分标准」是一段可编辑文本，原样作为提示词交给 AI。

## 十、复习

- 入口与界面：主界面“复习”进入“复习选择界面”；布局与交互参照背诵选择界面；
  用户可选择“默认复习模式”或“复习卡片”。
- 复习优先度与排序：每个词有“复习优先度”；默认复习模式排序为
  ①复习优先度 → ②背诵优先级 → ③单词首字母。
- 复习卡片模式：先选一张卡片（列表支持筛选、排序、搜索）再确认选择；范围限定为该卡片出现过的单词。
- 流程：按上述顺序逐个呈现；复习完所有词后再点“下一个”只提示、不再新增；
  单词呈现机制（展示方式、切换逻辑）与背诵完全一致。
- 与背诵一致的能力：底部四个按钮（下一个 / 再次记忆 / 复习完了 / 退出复习）；
  每点“每出现几个单词”次“下一个”自动开始一轮考核；「再次记忆」手动开始（1.0.0 补齐）。
- 卡片模式筛选与排序（1.0.0 完善）：搜索（卡片名称或卡片里的单词）、状态、词数下限、
  排序（最近改动 / 创建时间 / 名称 / 词数 + 升降序）、结果计数、重置。
- “复习完了”写回复习次数、上次复习时间与重算后的复习优先度。

## 十一、拼写强化

- 定位：主背诵程序之上的拓展功能，针对能听懂、认识但常拼错的词；不引入新的单词状态，
  标记进入本流程时自动把状态改为“已背”。
- 入口与流程：主界面“拼写强化” → 功能首页（待强化单词情况 + “开始复习”）→ 按本功能专属优先级选词生成队列
  → 拼写界面（中文意思、提示框、输入框、提示栏）→ 确认或 Enter 切到单词卡 → 任意键进下一题 → 结束可给简要总结；
  整个功能内右下角常驻“退出”，退出不丢已记录成绩。
- 拼写界面：自上而下为中文意思（中部、大字号）、提示框（词性等，空则留白）、输入框（Enter = 确认）、
  提示栏（提示 / 小喇叭 / 确认）；小喇叭与提示每点一次各扣 1 分；提示逐次追加显示答案字母。
- 计分：每题满分 5，扣分下限 0；拼写本身不额外扣分；确认提交时的剩余分即本题得分。
- 选词与调度：标记（“仅拼写”）的词进入本流程，重复标记无影响；专属**加权公式**（属性名与主程序一致，
  权重可配置）；每次按优先级降序取配置的条数，不足取实际数量；满分词本轮不再出现，
  未满分词间隔 5 个单词后重现（剩余不足 5 个则追加到末尾）。
- 数据：复用主程序数据模型与存储层，不新建词表字段；持久化每个词的**历史得分与出现次数**。
- 界面标识：正确 / 错误使用圆形底色（正确绿色、错误红色）加白色勾叉图标。

## 十二、设置

- “外观”分类新增两项：
  - 分辨率大小：提供可调的分辨率尺寸选项；
  - 字体大小：影响背诵界面中的“单词”“中文含义”“按钮”“义项数角标”“统计信息”等白纸本体文字，
    三者相对比例不变；单词卡等弹窗字号不受影响。
- 新增主分类“音频设置”：完全按照旧版本的样子原封不动恢复。
- 新增主分类“背诵设置”：
  - 每出现几个单词进行一次考核（生效）；
  - 每次考核数；
  - 分数阈值（对应第九节“分数低于固定值（可调）”）；
  - 考核评分标准：替换原“考核难易程度（低/中/高）”，可直接编辑并作为提示词交给 AI，初始内容由实现方生成一份。
- 新增主分类“拼写强化”：每次复习词数 + 专属公式的权重（可配置，便于调参）。

## 十三、AI 能力

- 义项整理（录入、单词列表、单词卡的「AI 重新整理义项」）：由 AI 合并同义义项、补词性、精简近义词。
- AI 选词（背诵方式 4）：口述条件 → 生成候选选中集 → 确认界面；多轮对话每轮携带全部上下文。
- AI 评分（考核英译中）：按《背诵设置 → 考核评分标准》打分，满分 5。
- AI 接口的地址 / 模型 / 密钥由用户在本机设置里填写，只存在本机浏览器，不上传、不同步。

## 十四、版本与发布

- 版本 x.x.x：大版本由用户指定；小版本每次“上传 git 仓库”时 +1；小小版本每次对话 +1；上层 +1 时下层清零。
- 每次对话都要更新《版本更新日志》；每次小版本更新都要更新《项目概述》。
- 用户说出的交互与逻辑要求都要记录到本文；冲突或修改的部分删除旧内容。
- 不要擅自推送至 GitHub（用户明确要求时按用户指令执行）。
