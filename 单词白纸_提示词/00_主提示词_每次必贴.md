## 1. 项目一句话

一个本地离线、单用户的背单词 Web 应用，名字叫「单词白纸」。核心特色是「白纸空间记忆」：单词随机散落在满屏白纸上，靠**位置 + 语音**建立记忆，配默写自测和可自定义的间隔复习优先度。

## 2. 技术栈（已定，不要替换）

| 项 | 选型 |

## 3. 硬约束（违反即不合格）

1. **分词分层**：`ui/pages/*` 只能通过 `dao/` 存取数据，只能调用 `services/` 和 `core/`；**任何页面文件里都不许出现 `indexedDB`、`localStorage`、`fetch(`**。
2. **DAO 全异步**：`dao/` 导出的一切函数返回 `Promise`，即使底层是同步的。将来会把 IndexedDB 换成后端 API，接口签名不许变。
3. **零魔法数字**：所有可调数字集中在 `src/core/config.ts` 的 `DEFAULTS` 里，代码里不许写死 `30`、`10`、`3`、`2`。
4. **TypeScript strict**：不许用 `any`（确实需要时写 `unknown` + 类型守卫），不许 `@ts-ignore`。
5. **一个文件一件事**：单文件超过 300 行就该拆分。
6. 每个导出的函数/类型写一行 JSDoc 或注释说明用途。

## 5. 核心数据模型（`src/core/types.ts`）

```ts
export type WordStatus = 'unlearned' | 'learning' | 'learned' | 'chopped';

export interface Sense {
  id: string;
  text: string;        // 义项文本，可含词性前缀，如 "n. 苹果"
  aliases: string[];   // 近义词/等价写法，记忆判分时视为通过
  enabled: boolean;    // false = 被划掉
}

export interface Attrs {
  needSpell: boolean;      // 属性1 是否拼写
  failCount: number;       // 属性2 未通过次数（有上限，默认 2）
  failCountTotal: number;  // 内部真实累计，不设上限
  reviewCount: number;     // 属性3 复习次数
  lastReviewAt: number | null;  // 属性4 上次复习时间戳
  learnedAt: number | null;     // 属性5 首次背诵完成时间
  reviewPriority: number;       // 属性6 复习综合优先度
}

export interface Word {
  id: string;
  en: string;
  phonetic: string;
  example: string;
  senses: Sense[];
  sourceId: string;
  rawSources: { sourceId: string; senses: Sense[] }[];  // 低优先级来源记录，供手动采纳
  attrs: Attrs;
  status: WordStatus;
  learnOrder: number | null;   // 背诵顺序序号，已背词排序用
  createdAt: number;
  updatedAt: number;
}

export interface Source {
  id: string;
  name: string;
  priority: number;   // 数字越大越优先（方向可在设置里反转）
  createdAt: number;
}

export interface Session {
  id: string;
  type: 'learn' | 'review';
  wordIds: string[];                        // 唯一被持久化的部分
  placements: Record<string, { x: number; y: number }>;  // 白纸落点，仅内存
  shownIds: string[];                       // 已出现过的
  memorizeCount: Record<string, number>;    // 每词被「记忆」次数
  spellEnabled: boolean;
  finished: boolean;
  createdAt: number;
}
```

## 7. 全局交互规则（所有页面都要遵守）

- 「下一个」快捷键 = **Enter**
- 朗读三处入口：单词出现时自动读、悬停发音标识点击重读、单词卡上可再读
- **统一作答闭环**（记忆环节、拼写环节都走这套）：提交 → 立刻弹出正确答案单词卡 → 再次点击卡片 → 卡片消失 → 进入下一个
- 被「斩」的词：背诵、复习、记忆、推荐数字中**均不再出现**；列表页可「复活」
- 「拼」= 把 `attrs.needSpell` 置 true；影响是否进入拼写环节 + 属性 6 计算
- 未通过可无限次发生（`failCountTotal` 一直加），但 `failCount` 封顶在配置值（默认 2）；封顶后该词仍按未通过处理（记忆环节仍必抽）

## 8. 星号参数（`config.ts` 的 `DEFAULTS`）

| key | 默认 | 含义 |
|---|---|---|
| `learnMaxCount` | 30 | 背诵单次上限 |
| `memorizeMaxPick` | 10 | 单词未出完前，一次「记忆」最多抽几个 |
| `memorizeTargetCount` | 3 | 每词至少记忆几次才可结束 |
| `failCountCap` | 2 | 属性2 未通过次数上限 |
| `reviewGroupSize` | 30 | 复习每组上限 |

其他设置项：`paper`（尺寸/自适应/固定比例）、`display`（字体/字号/颜色/动效）、`parse`（字段分隔符/义项分隔符/优先级方向）、`memorizePosition`（`origin` 原位置 | `centerTop` 居中偏上，默认 `centerTop`，偏移量 `memorizeOffsetY` 可调）、`priorityExpr`（自定义表达式，默认用预设 `balanced`）、`ai`（`endpoint` / `model` / `key`，**全部由用户自己填**）。

### 8.1 AI 接入方式（牢记，别写偏）

这是插件里最常见的做法：**代码里只有一个通用接口位，地址和密钥由每个用户、每台设备自己填**。

- 配置只有三项：`endpoint`（接口地址）、`model`（模型名）、`key`（密钥）
- 代码里**不许写死任何厂商判断逻辑**（不许出现 `if (baseUrl.includes('deepseek'))` 这类分支）
- `DEFAULT_SETTINGS.ai` 只作为**默认值预填**，用户改成任何 OpenAI 兼容地址都照发不误
- 请求格式固定：POST `{ endpoint 规范化后 }/chat/completions`，头带 `Authorization: Bearer {key}`，body 为标准 OpenAI 格式
- **兼容目标只有 DeepSeek 官方一个**，其他兼容服务能填通就算赚的，不做专门适配、不做厂商白名单
- 密钥只存在这台设备浏览器的 localStorage 里，不上传、不同步；设置页要写清这个提醒
