## 第一部分：删除主界面「记忆」入口

### 1.1 要删什么

主界面现有 7 个入口：`录入 / 背诵 / 记忆 / 单词列表 / 复习 / 知识点 / 设置`

**删除主界面的「记忆」按钮**，保留 `背诵 / 录入 / 单词列表 / 复习 / 知识点 / 设置` 六个。

### 1.2 不要删什么（重要）

**「记忆」环节本身必须完整保留**，它现在是**背诵流程的内嵌环节**：

- 背诵页里，「再背一个」累计点 3 次（可配置）后自动变成「记忆」
- 背诵页右下角有独立的「再次记忆」按钮
- 点它们会进入默写自测流程

**所以只是删主界面的入口，不是删功能。** 具体：
- 保留 `MemoryStage` / 记忆相关的所有组件、逻辑、DAO 调用
- 保留背诵页对记忆环节的调用
- 若要删路由 `#/memory` 的独立入口，先确认没有其他页面链到它；若背诵页内部是靠组件调用而非路由跳转，删路由安全

**代码要求**：删完后全局搜索确认没有"孤儿引用"（某个按钮或链接指向已删除的入口，点了会空白）。

## 第二部分：背诵抽词 —— 绝对优先

### 2.1 规则（用户明确要求）

**优先级高的单词，优先被「背诵」抽中，是绝对优先，不是概率高。**

即：先把所有 `priority=5` 的词抽完，才开始抽 `priority=4` 的，以此类推。

### 2.2 实现

```ts
// src/core/pickWords.ts（新增或改现有的抽词函数）
export function pickNextForLearn(words: Word[], appearedIds: Set<string>): Word | null;
```

**候选池**：`status` 为未背/学习中，**且未被斩**，**且不在 appearedIds 里**的词。

**排序**：
1. `priority` **降序**（5 → 1）—— 第一关键字，绝对优先
2. 同级内：`createdAt` **升序**（先录入的先背）

取排序后的第一个。

### 2.3 影响范围

- 背诵页点「再背一个」→ 用这个函数取下一个词
- 复习环节的推荐/抽词**保持原逻辑**（仍按综合复习优先度），**不受本次改动影响**
  （用户只说了"背诵系统抽中"，复习有自己的优先度体系）

### 2.4 配置

在 `config.ts` 加：
```ts
learnPick: {
  samePriorityOrder: 'createdAt' | 'random';   // 默认 'createdAt'
}
```
默认 `createdAt`（可预测），用户可在设置里改成 `random`。

## 第三部分：列表页支持优先级

在单词列表页增加：

1. **显示**：每行/卡片显示优先级徽章，如 `P5` `P3`，高优先级用醒目颜色（如 P5 红、P4 橙、P3 灰）
2. **筛选**：筛选区加「优先级」下拉（全部 / P5 / P4 / P3 / P2 / P1）
3. **排序**：排序选项加「优先级（高→低）」
4. **编辑**：详情/编辑弹窗里可改优先级（下拉 1~5），改完立即生效并同步
5. **批量**：批量选中后可「设为优先级 X」

这样优先级系统才真正可用、可验证、可调整。

**要求**：
- **不要 `git push --force`**
- 若 `git push` 报"没有 upstream"，改用 `git push -u origin <当前分支名>`（先用 `git branch --show-current` 查分支名）
- 若报认证失败（权限、token、SSH key），**停止并把完整错误原样输出**给用户，说明需要什么（比如需要在终端登录 GitHub、或配置 SSH key）
- 推送成功后，输出：分支名、commit hash、仓库地址

## 验收标准

### 界面
1. 主界面只剩 6 个入口，**没有「记忆」**
2. 全局搜索确认没有指向已删入口的孤儿链接（点了不会空白）
3. 「记忆」环节**仍能正常工作**：进背诵页 → 点「再背一个」3 次 → 按钮变「记忆」→ 能进默写；或点「再次记忆」→ 能进默写

### 抽词绝对优先
4. **构造测试数据**：造 10 个词，5 个 `priority=5`，5 个 `priority=1`，全部未背
5. 进背诵页，连续点「再背一个」10 次：
   - **前 5 次必须全是 priority=5 的词**（顺序按 createdAt）
   - **第 6 次才开始出现 priority=1 的词**
6. 重复测 3 次，结果一致（证明是绝对优先，不是概率）
7. 混入 priority=3 的词：顺序必须是 5 全部 → 3 全部 → 1 全部

### 列表页
8. 列表页能看到优先级徽章
9. 按 P5 筛选 → 只剩优先级 5 的词
10. 按优先级排序 → 从高到低
11. 编辑某个词优先级为 5 → 立刻生效；进背诵页，它应该被优先抽到

### 回归
12. 一期原有功能完好：录入（txt/docx/pdf）、背诵全流程、记忆环节、复习、设置、云同步
13. 二期（若已装）功能完好
14. `npx tsc --noEmit` 零报错，`npm run build` 通过
