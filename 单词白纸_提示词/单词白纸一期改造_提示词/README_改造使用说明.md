# 一期改造 · 使用说明（先读这页）

> 这是**一期（单词模块）收尾改造**的提示词，共 3 个阶段。
> 前置条件：项目已完成本地版 01~08 + 同步版 01~07（+ 可选二期 01~07）。

## 标准流程

每次**开新对话**：

1. 先贴 `00_同步版主提示词_每次必贴.md` 全文（来自《单词白纸同步版_提示词》包）
2. 再贴本目录的 `R1_` / `R2_` / `R3_` 某一个阶段文件全文
3. 发送，等它写完
4. 按该文件末尾的「验收标准」逐条验证
5. 有问题就**在同一对话里**让它改，改到全绿
6. 每阶段验证通过后让它 `git commit` 一次
7. **R3 阶段最后会执行 `git push` 推到 GitHub**

> 每次都贴 00 是必须的——它锁死了技术栈（Vercel + Turso + 方案 B）、数据模型、空间隔离、本地优先等硬约束。

## 三个阶段

| 阶段 | 内容 | 关键点 |
|---|---|---|
| **R1** | 录入格式拓展（txt / docx / pdf）+ **优先级系统重置** | 装 mammoth、pdfjs；给 Word 加 `priority` 字段 |
| **R2** | 预设词库（4级/6级等）用 AI 重新整理义项 | **不改变优先级**，只重划义项/近义词 |
| **R3** | 删主界面「记忆」按钮 + 背诵抽词**绝对优先** + 列表页优先级 + **推送 GitHub** | 最后一步会 push |

## 关于删除「背诵 和 记忆」中的一个

**我的判断：删除主界面的「记忆」入口按钮，保留「背诵」。**

理由：
- 「记忆」环节（默写自测）**依赖背诵时已出现的单词列表**，无法独立存在
- 在现有交互里，记忆已经**内嵌在背诵页**里了——「再背一个」点 3 次自动变「记忆」，还有独立的「再次记忆」按钮
- 所以主界面上再放一个「记忆」入口，点进去是无根之木，确实冗余

**执行方式**：只删入口按钮，记忆环节的代码、调用、数据全部保留，由背诵页继续调用。
（如果你其实是想删「背诵」保留「记忆」，告诉我，我改提示词。）

## 改动不能破坏的东西

每阶段验收都有一条回归要求：
- 一期原有功能（背诵流程、记忆环节、复习、列表、设置、云同步）
- 二期（如果已装）：知识卡片、录入、学习、复习流程

## 关于 GitHub 推送（R3）

dsh 会执行 `git add / commit / push`。
如果它报"认证失败"或"没有 upstream"，它会明确告诉你缺什么——**把它的原话发给我**，我帮你处理。
