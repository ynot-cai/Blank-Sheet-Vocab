# 阶段 04：单词列表页

> 前置：阶段 01~03 已完成，库里已经有词。

## 任务

### 1. `src/ui/pages/ListPage.ts`

**顶部统计条**：总词数 / 未背 / 学习中 / 已背 / 已斩（5 个可点击的数字，点了就切成对应状态筛选）

**筛选区**（一行排开，可换行）：
- 搜索框：同时匹配英文和中文义项（含 aliases），不区分大小写，输入防抖 300ms
- 状态多选：未背 / 学习中 / 已背 / 已斩
- 来源下拉（全部 / 各来源）
- 「只看需拼写」开关
- 「未通过次数 ≥」数字输入
- 「复习优先度 ≥」数字输入（配合下面的排序做成"该复习了"快捷视图）
- 排序下拉：背诵顺序 / 复习优先度 / 创建时间 / 字母序 + 升降序切换
- 「重置筛选」按钮
- 右侧：每页条数（50/100/200）+ 分页组件

**表格列**：

| 列 | 内容 | 交互 |
|---|---|---|
| ☐ | 复选框 | 支持全选/反选，选中后出现批量操作条 |
| 单词 | 英文 + 音标（小灰字） | 点击单词 → 弹出 WordCard 详情（可编辑） |
| 义项 | 前 2 个义项 + 「+n」展开；被划掉的显示为灰色删除线 | 点击展开全部义项 |
| 来源 | 来源名 + 优先级 | — |
| ①拼 | 是否拼写，勾选框 | 直接改 `attrs.needSpell` |
| ②未通过 | `failCount`（上限值用红字标出达到上限的）/ `failCountTotal` 小字 | 可点击编辑（弹出数字输入） |
| ③复习次数 | 数字 | 可编辑 |
| ④距上次复习 | 「3 天前」/「未复习」 | 只读 |
| ⑤距背诵 | 「5 天前」/「未背」 | 只读 |
| ⑥优先度 | 数值（保留 2 位小数） | 只读，带「重算全部」按钮 |
| 状态 | 彩色小标签 | 下拉可切（除 chopped 用专门按钮） |
| 操作 | 详情 / 斩 / 更多 | 「更多」下拉：复活、复制、删除、查看其他来源义项 |

**批量操作条**（选中 ≥1 时从底部滑出）：
- 批量斩 / 批量复活 / 批量标记需拼写 / 批量取消需拼写 / 批量设为未背 / 批量删除（二次确认）
- 显示「已选 N 个」+「取消选择」

**「查看其他来源义项」弹窗**：
展示 `rawSources` 里每条来源的义项列表，每条一个「采纳为主义项」按钮（点后替换 `senses`，原 `senses` 反向塞进 `rawSources`）

**顶部右侧常驻按钮**：
- 「导出备份」「导入备份」（复用阶段 02 的 `services/backup.ts`）
- 「重算优先度」：对所有词跑一遍 `computePriority` 并写回 `attrs.reviewPriority`

### 2. `src/ui/components/WordCard.ts`（复用组件，本阶段先做列表版）

```ts
export function renderWordCard(
  word: Word, 
  opts: { 
    editable?: boolean;         // 列表/背诵页 true；记忆环节的答案卡 false
    showAnswer?: boolean;       
    onChange?: (next: Word) => void;
    onChop?: () => void;
    onSpell?: () => void;       // 「拼」按钮，仅背诵页用
    onClose?: () => void;
  }
): HTMLElement;
```

内容：英文（大）+ 音标 + 发音按钮（🔊）+ 义项列表（用 `SenseEditor`）+ 例句。
`editable` 时：音标、例句、义项全部可就地编辑，改动通过 `onChange` 回调（由调用方决定何时写库）。

### 3. 时间显示工具

在 `src/core/model.ts` 加：
```ts
export function humanizeDays(ts: number | null, now?: number): string;
```
返回：`未复习` / `今天` / `1 天前` / `23 天前` / `3 个月前`（≥90 天按月）。

### 4. 路由与入口

`App.ts` 的「单词列表」按钮点亮，跳 `#/list`。

## 验收标准

1. `npx tsc --noEmit` 零报错，`npm run build` 通过
2. 导入 200+ 词后页面不卡（分页生效，单页 ≤200 条）
3. 搜索中文能搜到（包括通过 aliases 命中）
4. 勾选「只看需拼写」+「未通过 ≥1」两个条件能叠加生效
5. 改任意属性（拼/未通过/复习次数）后刷新页面仍保留
6. 斩词后从默认视图消失，切到「已斩」能看到并复活
7. 已背的词按 `learnOrder` 排序时顺序正确（本阶段 `learnOrder` 可能还是 null，排序时把 null 排最后）
8. 「重算优先度」后 ⑥ 列数值变化，且切换设置页的预设再重算，数值跟着变
