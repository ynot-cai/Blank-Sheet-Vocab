# 需要你自己做的事 · Vercel + Turso 部署手册

> 这份是给你（人）看的。dsh 负责写代码，你负责注册两个免费账号、点几下。
> **全程不用买服务器、不用备案、不用配 HTTPS、不用装 Docker。预计 1~2 小时。**

---

## 先看：为什么这次这么省事

| 以前（国内服务器方案） | 现在（Vercel + Turso） |
|---|---|
| 买服务器（几百/年） | **0 元** |
| 等备案（3~4 周） | **不用备案**（服务器在海外） |
| 装 Docker、配 Nginx | **不用** |
| 自己申请 SSL 证书 | **Vercel 自动给** |
| 自己维护服务器 | **不用，Vercel 全托管** |
| 买域名 | 可选（先用免费 `.vercel.app` 域名） |

**为什么不用备案？**
备案针对的是"服务器在中国大陆"。Vercel 的服务器在海外，你的域名只是指向海外，属于访问境外网站，**不需要 ICP 备案**。（域名本身如果在国内注册商买，需要实名认证，但不用备案。）

## 全局流程

```
① 注册 GitHub 账号（前提）
② 注册 Turso → 建一个数据库 → 拿到 URL + token
③ 注册 Vercel → 导入项目 → 填环境变量 → 部署
④ 手机/平板打开网址 → 填同一个同步码 → 添加到主屏幕
⑤ 日常：定期导出备份
```

## 第 1 步：注册 Turso 并建数据库

### 1.1 注册
1. 打开 https://turso.tech
2. 点 **"Start for free"** / "Try Cloud free"
3. 用 **GitHub 账号登录**
4. 免费版足够：5GB 存储、5亿次读/月、100 个数据库（你只用 1 个）

### 1.2 创建数据库（网页方式，推荐）

1. 登录后进入控制台，点 **"Create Database"**
2. 名字填 `wordpaper`
3. **区域选亚太**：优先选 `Hong Kong (hkg)` 或 `Singapore (sin)` 或 `Tokyo (nrt)`——离中国近，延迟低
4. 点创建

### 1.3 拿到连接信息（关键，记下来）

创建完成后，进入数据库详情页，找到两样东西：

| 名称 | 长什么样 | 在哪找 |
|---|---|---|
| **Database URL** | `libsql://wordpaper-你的用户名.turso.io` | 详情页顶部，有个复制按钮 |
| **Auth Token** | 一长串字符（点一次生成一次） | 点 "Create Token" / "Generate Token"，复制下来 |

⚠️ **Token 只显示一次**，复制后先粘到记事本里存好，关掉就找不回来了（可以重新生成一个新的）。

> **另一种方式（命令行，可选）**：
> ```bash
> curl -sSfL https://get.tur.so/install.sh | bash
> turso auth login          # 用 GitHub 登录
> turso db create wordpaper --location hkg
> turso db show wordpaper          # 显示 URL
> turso db tokens create wordpaper # 生成 token
> ```
> 网页方式更直观，新手推荐网页。

## 第 2 步：注册 Vercel 并部署

### 2.1 注册
1. 打开 https://vercel.com
2. 点 **"Sign Up"**
3. 用 **GitHub 账号登录**（Hobby 免费版，个人项目够用）

### 2.2 导入项目

**方式 A：Git 导入（推荐，以后改代码自动重新部署）**
1. 先把你的项目推到 GitHub 仓库（私有仓库也行）
2. Vercel 控制台 → **"Add New" → "Project"**
3. 从 GitHub 列表里选你的 `wordpaper` 仓库 → Import
4. Vercel 会自动识别是 **Vite** 项目，构建命令默认 `npm run build`、输出目录 `dist`——**一般不用改**
5. 先**不要**点 Deploy，先填环境变量（见 2.3）

**方式 B：命令行部署（不想折腾 Git 就用这个）**
```bash
npm i -g vercel
vercel login
# 在项目根目录执行
vercel --prod
```

### 2.3 填环境变量（最重要，填错就连不上数据库）

在 Vercel 项目页面 → **Settings → Environment Variables**，逐个添加：

| 变量名 | 值 | 说明 |
|---|---|---|
| `TURSO_DATABASE_URL` | `libsql://wordpaper-xxx.turso.io` | 第 1.3 步拿到的 URL |
| `TURSO_AUTH_TOKEN` | 那一长串 token | 第 1.3 步拿到的 token |
| `ALLOWED_ORIGIN` | 先填 `*` 或你的域名 | 见下方说明 |

**关于 ALLOWED_ORIGIN**：
- 部署后会得到一个域名，如 `https://wordpaper.vercel.app`
- **第一次**可以先填 `*`（允许所有来源），部署成功、确认域名后再改成精确域名
- **最终建议**改成你的实际域名（如 `https://wordpaper.vercel.app`），更安全
- 注意：**不要带结尾斜杠**

### 2.4 部署
1. 填完环境变量，点 **"Deploy"**（若已部署过，点 "Redeploy"）
2. 等 1~3 分钟
3. 部署成功后会给你一个域名：`https://wordpaper-xxx.vercel.app`

### 2.5 验证部署成功

浏览器打开：
```
https://你的项目.vercel.app/api/health
```

应该看到：
```json
{ "ok": true, "db": "connected", ... }
```

- 看到 `db: "connected"` → 数据库连上了，成功！🎉
- 看到 500 或 `db: "error"` → 环境变量填错了，回去检查（**改完环境变量必须 Redeploy**）

## 第 3 步：配置你的应用

### 3.1 打开网站
浏览器打开 `https://你的项目.vercel.app`，应该能看到首页。

### 3.2 填同步码（每台设备都要填一次）

1. 进 **设置 → 云同步**
2. 打开「启用云同步」
3. **后端地址**：填 `https://你的项目.vercel.app`（**不要带 `/api`**，代码里会拼）
4. **同步码**：自己起一个字符串，比如 `my-word-2026`
   - 建议 8 位以上，字母+数字
   - ⚠️ **一定要记牢**（存密码管理器或记事本），服务器只有哈希，忘了找不回
   - ⚠️ **所有设备填同一个码**
5. 点「测试连接」→ 绿字成功
6. 点「立即同步」

### 3.3 在其他设备重复

手机、平板都打开同一个网址，填**同样的同步码**，就能看到同一份数据。

## 第 4 步：手机 / 平板添加到主屏幕

### iPhone（Safari）
1. Safari 打开你的网址
2. 点底部**分享按钮**（方框向上箭头）
3. 下滑找到「**添加到主屏幕**」

### Android（Chrome）
1. Chrome 打开网址
2. 点右上角「⋮」
3. 选「**添加到主屏幕**」或「安装应用」

之后从桌面图标点开，就是全屏 App 体验，没有地址栏。

### 手机使用提示

## 第 5 步：⚠️ 国内访问说明（必读）

### 可能遇到的问题
Vercel 在大陆没有服务器，`*.vercel.app` 这个域名**在部分地区可能被 DNS 污染或访问慢**——表现是有时打不开、有时很慢。

### 但对你影响很小（重要！）

**因为你的应用是"本地优先"架构**：
- 单词数据**全部存在你自己设备的浏览器里**
- 打开应用**立刻能用**，不等网络
- 同步只是**后台悄悄进行**

所以：**即使 Vercel 暂时访问不了，你照样能背单词、看列表、记忆、复习。** 只是多设备同步会延后——等网络好的时候（或换个网络、或用手机流量）它会自动补上。

这就像微信断网了还能看聊天记录、发消息排队一样。

### 如果确实经常打不开，两个改善办法

**办法 1：绑定自己的域名（推荐，成本几十块/年）**
1. 在腾讯云/阿里云买个域名（几十块/年，需实名认证，**不用备案**，因为指向海外）
2. Vercel 项目 → Settings → Domains → 添加你的域名
3. Vercel 会告诉你填什么 DNS 记录（一般是 CNAME）
4. 去域名控制台填上，等几分钟生效
5. 把 `ALLOWED_ORIGIN` 改成你的新域名，重新部署

自定义域名比 `vercel.app` 更不容易被干扰。

**办法 2：接受它**
反正本地能用，同步偶尔卡一下无所谓。等哪天心血来潮再换域名。

## 第 6 步：日常维护（很少，但要有）

### 定期导出备份（唯一的保险）⚠️

浏览器里的数据**会因为清缓存而丢失**。这是这套方案唯一的真实风险。

**请养成习惯**：每隔一段时间（或录完一批词后），去 **设置 → 导出备份**，下载一个 json 文件，存到网盘或自己电脑。

（更好：设置页里连一个"本地文件夹自动备份"，之后每次改动自动写文件，见本地版阶段 02 的功能。但**手机上没有这个能力**，所以还是要手动导出。）

### 更新版本
- 如果用 Git 导入：**本地改完代码 `git push`，Vercel 自动重新部署**
- 如果用命令行：改完再跑一次 `vercel --prod`

### 查看日志 / 排查问题
Vercel 项目页面 → **Logs** 或 **Functions** 标签，能看 API 的报错。

### 免费额度够吗？
- **Vercel Hobby**：每月 100GB 流量、函数 100 万次调用——个人用远远够
- **Turso Free**：5GB 存储、5亿次读/月——你的词库撑死几百 MB，够用一辈子

## 常见问题

**Q：一年花多少钱？**
A：**0 元**（用免费域名）。如果买个自己的域名，几十块/年。没有服务器费用。

**Q：为什么不用备案了？**
A：服务器在海外（Vercel），不属于大陆托管，所以不需要 ICP 备案。域名在国内买的话要实名，但不用备案。

**Q：AI 密钥安全吗？**
A：安全。密钥只存在你自己的浏览器里，服务器（包括那个代理）**不存储、不记录、不接触**你的密钥。服务器上只有同步码的哈希值。

**Q：同步码忘了怎么办？**
A：找不回来（服务器只有哈希，没有明文）。所以**一定要定期导出备份**——备份文件里有你的全部单词数据。同步码本身请存到密码管理器。

**Q：换手机了怎么办？**
A：新手机打开网址 → 填同一个同步码 → 自动拉回数据。如果同步码也忘了，就用之前导出的备份 json 导入。

**Q：能在公司/学校电脑上用吗？**
A：能，只要能打开网页。但公共电脑**不要保存同步码和 AI 密钥**（用完清缓存）。

**Q：将来想公开给别人用呢？**
A：架构已经预留好了——把"同步码"换成"邮箱注册"即可，数据模型只需把 `spaceKey` 改成 `userId`，业务代码几乎不用动。但公开前要重新考虑：大陆用户访问速度、合规要求等。
