## 任务

### 1. 数据说明页（新增路由 `#/about`）

自用工具，语气可以直白，核心讲清"我的数据到底在哪"。内容要点：

**数据存在哪（三层）**
1. **浏览器本地（主）**：单词、学习记录、AI 配置都存在你当前设备的浏览器里。断网也能用。
2. **云端数据库（同步用）**：开启同步后，单词数据会同步到 Turso 数据库，用于多设备共享。
3. **本地备份文件（可选）**：连接本地文件夹后，每次改动自动写一个 `wordpaper-data.json`。

**服务器存什么、不存什么（重点突出）**
- ✅ 存：你的单词数据、同步码的**哈希值**（SHA-256）
- ❌ 不存：你的 **AI 接口密钥**（只在你自己浏览器里，服务器全程不接收、不存储）
- ❌ 不存：你的姓名、手机号、位置等任何个人信息
- ❌ 不做：用户追踪、行为分析、广告

**安全说明**
- 全站 HTTPS（Vercel 自动签发证书）
- 同步码只以哈希形式存储，服务器不知道明文
- AI 密钥和同步码都由你自己保管，请定期导出备份

**数据怎么删**
- 设置页可清空云端数据
- 浏览器设置里清除网站数据 = 删除本地存储
- 换同步码 = 换一个全新的数据空间（旧数据在旧码下，不影响使用）

**免责**
- AI 生成的释义、例句可能有误，请自行甄别
- 本工具为个人自用项目，按"现状"提供

### 3. 上线自检清单（生成 `CHECKLIST.md`）

一份可勾选的清单，部署完逐项确认：

**功能自检**
- [ ] 首页 6 个入口都能进
- [ ] 录入 → 解析 → 合并 → 入库，全流程通
- [ ] 背诵：单词出现、朗读正常、点单词出/收中文意思
- [ ] 「再背一个」点 3 次后变「记忆」；「再次记忆」能立即记忆
- [ ] 「保存并退出」能保存位置和记忆次数；重进能恢复
- [ ] 「背完了」在每词记忆 3 次后出现，点击能归档
- [ ] 记忆：默写、判分、答案卡"点任意处继续"（含空格/Enter）
- [ ] 复习：分组、推荐数字
- [ ] 列表：搜索、筛选、改属性、斩/复活
- [ ] 云同步：手机/电脑填同一同步码能同步
- [ ] 断网：应用能打开，本地功能全部可用

**多端自检**
- [ ] 手机上：右下角 4 个按钮竖排、不置灰、能点
- [ ] 手机上：单词后有浅灰序号（1 个义项不显示）
- [ ] 手机上：单词没有发音按钮、没有 hover 工具条
- [ ] 手机上：撒满一屏后按钮区没压住单词
- [ ] 平板上：同上，布局合理
- [ ] 添加到主屏幕成功，点开是独立窗口
- [ ] iOS 语音：首次点击解锁后能朗读

**安全自检**
- [ ] `ALLOWED_ORIGIN` 填的是自己的域名（不是 `*`）
- [ ] 代码里搜不到"存储 AI 密钥"的逻辑
- [ ] `api/ai-proxy.ts` 不连接数据库
- [ ] 数据库里没有存密钥的表
- [ ] 日志里搜不到密钥明文
- [ ] 非白名单来源请求代理 → 403

**同步自检**
- [ ] `/api/health` 返回 `{ ok: true, db: "connected" }`
- [ ] 用 illegal spaceKey 请求 → 401
- [ ] 用不同 spaceKey 拉取 → 数据隔离（拉不到别人的）
- [ ] 单批推送 ≤ 500 条，超过返回 400
