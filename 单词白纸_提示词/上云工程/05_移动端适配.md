# 阶段 05：移动端适配（手机 + 平板）

> 前置：阶段 01~04 已完成，云端同步可用。
> 目标：手机、平板上体验可用。**不是套个响应式就完事**——交互是给触摸重新设计的。

---

## 0. 重要：当前交互基线（本地版已变更，适配必须基于此）

**本地版的背诵/记忆交互已经改版，下面的规则是"现状"，移动端适配必须在这个基础上做，不要按旧版（预选数量 / hover 工具条 / 「下一个」按钮）来写。**

### 0.1 背诵页不再预选数量

进入背诵页**不需要先选背多少个词**，直接开始。

### 0.2 右下角按钮竖排（所有按钮集中右下角）

从**下往上**依次排列（这是我的排布建议，若你现场觉得不顺手可微调，但要保持"集中右下角"）：

```
        [背完了]        ← 仅当每个词都至少记忆 3* 次后才出现（红色）
      [保存并退出]
       [再次记忆]
      [再背一个]        ← 最下方，主按钮
```

| 按钮 | 行为 |
|---|---|
| **再背一个** | 出现下一个单词（原「下一个」）。**每累计点击 3\* 次（可配置，默认 3），此按钮自动变为「记忆」**，点它就是一次记忆环节；记忆完成后变回「再背一个」并清零计数 |
| **再次记忆** | 在「再背一个」上方，按下**立即**进行一次记忆环节（不受 3\* 计数限制） |
| **保存并退出** | 保存当前**完整进度**：每个单词的位置坐标、每个单词已进行的记忆次数、已出现列表。下次进入可恢复 |
| **背完了** | 仅当**每个单词都至少记忆了 3\* 次**后才出现（红色）。点击 → 单词归档，完全结束本次背诵 |

**按钮永不置灰**——即使条件不满足也保持可点（点不满足条件的按钮给轻提示即可，不要变灰）。

### 0.3 中文意思的显示规则（背诵页）

- 每点一次「再背一个」，**最新出现的那个单词的正下方**自动显示中文意思
- **只对最后出现的这一个单词生效**，之前的单词不显示
- 格式：`词性.①义项1②义项2`（如 `n.①苹果②苹果树`）
- **只显示"代表义项"，不显示近义词**（代表义项在录入时指定，其余作近义词存 `aliases`）
- **点击单词** → 中文意思**消失**（切换）
- **再点击单词** → 中文意思再次出现
- **点击中文意思本身** → 弹出单词卡

### 0.4 单词卡排版（新，必须遵守）

```
┌────────────────────────────┐
│  abandon  n.①放弃②抛弃      │  ← 中文意思：纯黑、醒目、紧跟单词后
│  /əˈbændən/  🔊             │  ← 音标在单词下方，喇叭在音标旁
│  He abandoned his car.      │  ← 例句在音标下方
│                            │
│ [查看义项] [标记拼写] [斩掉] │  ← 三个按钮并列在最下方
└────────────────────────────┘
```

- **中文意思**：字号加大、纯黑色（不加灰）、紧跟在英文单词后面
- **音标**：在单词下方一行
- **喇叭**：在音标旁边（点击重读）
- **例句**：在音标下方
- **底部三个按钮并列**：`查看义项` / `标记拼写`（「拼」）/ `斩掉`（「斩」）
- **必须手动点「查看义项」才会弹出具体的义项修改界面**（划掉/合并/加近义词）。卡片默认**不**展开义项编辑区

### 0.5 记忆环节规则

- **按任意处继续**：答案卡弹出后，**点击卡片、点击白色区域、按 Enter、按空格** 都能继续下一个（四种都支持）
- **抽词**：点「记忆」时，若**已出现的单词不足 10 个**，则只进行**等同于已出现单词数量**的测试，**不会**出现"还没出现但已被选中"的单词
- 未出现过的单词不参与本次记忆

### 0.6 录入时的义项代表

录入/合并义项时，要能**指定每个义项的代表**，其他说法作为近义词（`aliases`）。卡片和中文意思显示区**只显示代表**，不显示近义词。

## 1. 全局响应式基础

- `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">`
- 断点：手机 `< 768px` / 平板 `768px ~ 1024px` / 桌面 `> 1024px`
- 安全区适配（iPhone 刘海/底部横条）：`env(safe-area-inset-*)`，**右下角按钮要避开底部安全区**
- 禁止双击缩放；单词区域禁用长按选中和上下文菜单
- 触摸滚动：`-webkit-overflow-scrolling: touch`

---

## 2. 白纸背诵页适配（核心）

### 2.1 义项序号：平板和手机统一"主动显示"

**这是本次适配的重点。**

> 桌面版原逻辑是"鼠标移到单词附近才显示有几个义项"。**移动端没有 hover，这个交互在平板和手机上都不成立**，所以统一改为主动显示。

- 在**每个单词后面**跟一个**浅灰色小数字**，表示该词有几个义项
- **只有 1 个义项时不显示**（避免满屏都是"1"）
- 字号：跟随单词字号等比缩小（建议单词字号的 0.5 倍，**最小 12px**，确保能看清）
- 颜色：浅灰（如 `#bbb`），不抢单词本身的视觉
- 平板和手机**都显示**，保持行为一致

### 2.2 不再有悬停工具条和发音按钮

- **删除**"鼠标移到附近显示发音按钮"的悬停工具条（移动端无 hover）
- **单词旁边不再放发音按钮**（按用户要求，平板和手机都不放）
- 朗读入口只剩两个：单词出现时**自动朗读**、单词卡里的**喇叭**

### 2.3 右下角按钮区：必须处理遮挡

4 个按钮竖排堆在右下角，会遮挡撒到该区域的单词。两个措施**都要做**：

1. **布点避让**：调用 `jitteredGrid` 时，把右下角约 **140×220px**（手机）/ **180×260px**（平板）的区域标记为"安全区"，**撒词时不往这块放**
2. **按钮半透明**：按钮背景用半透明（如 `rgba(255,255,255,0.85)` + 轻微阴影），万一重叠也能看见底下的词
3. 按钮最小尺寸 44×44px，手机上主按钮「再背一个」再大一号
4. 按钮区整体**上移避开 iPhone 底部安全区**

### 2.4 触摸交互映射

| 交互 | 移动端处理 |
|---|---|
| 点击单词 | 出/收中文意思（同基线 0.3），热区 ≥ 44×44px |
| 点击中文意思 | 弹单词卡（**底部弹出 bottom sheet**，可下滑关闭） |
| 卡片底部三按钮 | 手机上放大，间距加大，避免误触 |
| 「再背一个」 | 右下角主按钮，拇指舒适区 |
| Enter / 空格 | 保留（外接键盘可用），手机上不影响 |

### 2.5 单词与布点密度

- 手机上**字号调大**、**布点密度降低**（每屏建议最多 10~12 个），间距加大
- 平板上可参考桌面但略稀疏

---

## 3. 记忆环节适配

- **「按任意处继续」在手机上非常友好**（点白纸即继续），保持四种触发：点卡片 / 点白色区域 / Enter / 空格
- 输入框（填中文意思）：字号 **≥ 16px**（iOS 上小于 16px 会导致聚焦时页面自动放大，必须避免）
- 输入框在手机上**纵向排列**（横排会挤）
- 「提交」按钮固定在底部，避开软键盘
- 答案卡：底部弹出或全屏，**点任意处继续**保持

---

## 4. 其他页面

### 4.1 首页
- 桌面 6 个按钮横排 → **手机 2×3 大按钮网格**，按钮最小高度 ≥ 56px

### 4.2 单词列表页
- 桌面表格 → **手机改为卡片流**
- 每张卡：单词 + 音标 + 前 2 个代表义项 + 状态标签；操作（斩/编辑/详情）收进右上角「⋯」
- 搜索框 sticky 置顶；筛选条件收进抽屉

### 4.3 设置页
- 分区折叠保留；输入框高度 ≥ 44px、字号 ≥ 16px
- 同步码、AI 密钥等长串密码要方便粘贴（手机上输入很痛苦）
- 导出/导入按钮在真机上要能触发下载/文件选择

## 5. iOS Safari 语音解锁

iOS 上 `speechSynthesis.speak()` 首次必须在**用户手势回调内**触发，否则静音。

方案：
1. 首次进入背诵页显示「点击开始」引导层
2. 用户点击时，在回调里执行一次**静音朗读**解锁
3. 解锁后隐藏引导层
4. 文案：「点击屏幕开始（首次需要点击以启用语音）」，并提示**关闭 iPhone 侧边静音键**

## 6. 验收标准

1. `npx tsc --noEmit` 零报错，`npm run build` 通过
2. **模拟器测试**（iPhone + Android 各一）：
   - 右下角 4 个按钮竖排正确、不置灰、能点
   - 点「再背一个」→ 新词出现且**正下方有中文意思**，格式为 `词性.①义项1②义项2`，**只显示代表不显示近义词**
   - 再点该单词 → 中文意思消失；再点 → 又出现
   - 点中文意思 → 弹出单词卡（底部弹出）
   - 单词后跟**浅灰序号**，1 个义项的词**不显示**序号
   - 单词**没有**发音按钮，**没有**悬停工具条
3. **遮挡验证**：撒满一屏词后，右下角按钮区**没有**单词被压住（布点避让生效）
4. **记忆环节**：提交后，点卡片 / 点白色区域 / 空格 都能继续；只测已出现的词（<10 个时按实际数量）
5. **卡片排版**：中文意思纯黑醒目紧跟单词、音标在单词下方、喇叭在音标旁、例句在音标下；底部「查看义项/标记拼写/斩掉」并列；**默认不展开义项编辑**，点「查看义项」才展开
6. **真机测试**：iOS 语音能朗读（首次点击解锁后）；Android 正常
7. 所有可点击元素热区 ≥ 44×44px；iOS 输入框字号 ≥ 16px 不放大页面
8. **桌面不受影响**：hover、Enter 快捷键、原有右下角按钮照常
