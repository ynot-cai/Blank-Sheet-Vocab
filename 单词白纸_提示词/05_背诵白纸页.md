# 阶段 05：背诵白纸页

> 前置：阶段 01~04 已完成。这是本项目的核心特色页面，请做细。

## 任务

### 1. `src/core/layout.ts` 布点算法

```ts
export interface Placement { x: number; y: number; }   // 归一化 0~1 的相对坐标

export function jitteredGrid(count: number, opts?: {
  aspect?: number;       // 画布宽高比，默认 16/9
  margin?: number;       // 边距占比，默认 0.06
  seed?: number;
}): Placement[];
```

要求：
- 先按 `count` 和画布宽高比算出最接近的网格行列数（使格子尽量接近正方形），再在每格内做**抖动**（格内随机偏移，保留格宽的 20% 边距）
- 格子多于需求时随机抽掉多余的；格子不够时允许一格放两个（第二个偏移到格子右下角）
- 用可复现的伪随机（mulberry32 + seed），同一个 seed 结果稳定，便于调试
- 返回顺序要**打乱**（不能是按行列排下来的顺序），打乱用同一个 seeded random
- 保证不重叠：抖动后做一次轻量冲突检测，若两欧氏距离 < 阈值（格宽的 0.7）就把后一个挪到最近的空格

### 2. `src/core/tts.ts` → 放在 `src/services/tts.ts`

```ts
export function speak(text: string, opts?: { rate?: number; lang?: string }): void;
export function cancelSpeak(): void;
export function pickVoice(lang: string): SpeechSynthesisVoice | null;   // 优先选 en-US 的本地语音
export function isSupported(): boolean;
```

- 用 `settings.practice.speakRate` 和 `speakLang`
- 不支持时静默失败（console.warn），**不要弹窗打断背单词**
- 连续快速点击时先 `cancel()` 再 `speak()`，避免排队

### 3. `src/ui/pages/LearnPage.ts`

**进入流程**：主界面点「背诵」→ 弹一个小对话框「本次背多少个词？」+ 数字输入（上限 `learnMaxCount`，下面一行小字「最多 30 个，可在设置里改」）→ 确认后进白纸页

**抽词规则**（`dao.words.query`）：
- 只抽 `status === 'unlearned'` 且未被斩的词
- 排序：优先 `createdAt` 升序（先录入的先背），可由设置扩展（本阶段先写死，留 TODO）
- 数量不足时按实际可用数量进入，并 Toast 提示「可用未背词只有 N 个」

**白纸画布**：
- 满屏白色（用 `settings.paper` 决定尺寸：`auto` 铺满视口 / `ratio` 按比例居中留白 / `fixed` 固定像素居中，超出滚动）
- 没有任何边框、网格、页码，就是一张白纸
- 顶部有一条极淡的工具条（鼠标移到顶部才完全显现，避免破坏"白纸"感）

**单词呈现**：
- 用 `jitteredGrid` 算出全部落点，首个词出现时自动朗读
- 单词是绝对定位的 `<div class="paper-word">`，只显示英文（不显示音标、中文）
- 字号取 `settings.display.fontSize`
- 出现时有一个很轻的淡入 + 微缩放动效（动效开关关闭时直接显示）

**「下一个」按钮**：
- 页面右下角浮动按钮，文案「下一个 (Enter)」
- 点击/按 Enter → 下一个词落在下一个预设落点上并朗读
- 已出现的词**留在纸上不动**（这是空间记忆的关键，不要清除）
- 全部落点用完后 → 按钮变灰，Toast「本轮单词已全部出现，可以点『记忆』了」，并把 Enter 键转交给「记忆」按钮

**悬停标识**：鼠标移到某个单词附近（单词元素本身 + 周围 40px 热区）时，在单词右侧浮出一个小工具条：
- **序号标识**：一个圆形徽章，数字 = 该词 `activeSenses().length`，hover 提示「该词有 N 个义项（近义已合并）」
- **发音标识** 🔊：点击重读一遍
- 工具条不遮挡单词，鼠标移开后 200ms 淡出

**点击单词 → 单词卡**：
- 弹出 `WordCard`（`editable: true`），包含中文含义、例句、音标
- 卡片上三个按钮：
  - **「拼」**：把 `attrs.needSpell` 置 true，按钮变成「已标记拼写 ✓」，再点取消
  - **「斩」**：二次确认（小气泡「确定斩掉？斩后不再出现」）→ 单词从画布消失，`status='chopped'`
  - **关闭**（× 或点卡片外）
- 卡片支持就地编辑义项：划掉 / 合并 / 加近义词（复用 `SenseEditor`），改动立即写库（`dao.words.updateSenses`）
- 卡片打开时按 Esc 或点外部关闭

**顶部工具条**（hover 显现）：
- 进度「已出现 7/20」
- 「记忆」按钮（进入阶段 06）
- 「结束」按钮（本阶段先做成：点了就保存 session 的 wordIds 并回首页，Toast 提示「已保存本次词单」）
- 「返回」（同结束，但提示会保留词单）

**持久化**：进入页面时 `dao.session.saveSession({ type:'learn', wordIds, ... })`，只存 wordIds。落点 placements 存内存。

## 验收标准

1. `npx tsc --noEmit` 零报错，`npm run build` 通过
2. 选 20 个词 → 白纸铺满视口、纯白无边框
3. 连续按 Enter 20 次 → 20 个词全部出现，**分布均匀、无重叠、无扎堆**，且每个都朗读了
4. 悬停单词 → 出现序号徽章（数字等于该词义项数）和 🔊，点 🔊 会重读
5. 点单词 → 卡片出现，含音标/义项/例句；能划掉一个义项并保存（刷新后仍生效）
6. 点「拼」→ 该词 `needSpell` 变 true（列表页能看到）
7. 点「斩」→ 单词消失，刷新后不再出现在背诵抽词里；列表页「已斩」里能找到并复活
8. 窗口 resize 后单词相对位置不变（用归一化坐标渲染）
9. 全部出现后「下一个」变灰，Enter 不再加词
