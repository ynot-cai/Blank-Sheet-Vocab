# 阶段 06：记忆环节 + 拼写环节

> 前置：阶段 01~05 已完成，白纸页能出词。这是规则最密的一块，请严格按描述实现。

## 任务

### 1. 入口与抽词

白纸页顶部工具条的「记忆」按钮 → 进入 `MemorizePage`（复用同一个白纸画布，切换模式）。

**抽词算法**（写成 `src/core/pick.ts`）：

```ts
export function pickForMemorize(
  session: Session, 
  allWords: Word[], 
  cfg: { maxPick: number; targetCount: number }
): string[];
```

规则（按顺序执行）：
1. 候选池 = session.wordIds 里**未被斩**的词
2. **必抽**：所有本轮记过未通过的（`failCountTotal` 在本次 session 内增加过的，用 `session.failedIds: string[]` 记录）
3. 若还有名额：**优先抽尚未出现过的**（`!shownIds.includes(id)`）
4. 若还有名额：抽已出现过但记忆次数最少的
5. **上限规则**：只要 session.wordIds 里还有词没出现过（`shownIds.length < wordIds.length`），本次最多抽 `maxPick` 个（默认 10）；**但如果必抽的未通过词超过 maxPick，允许突破上限全部纳入**
6. 全部词都出现过后，不再受 maxPick 限制，一次抽完所有候选
7. 抽出后**随机打乱顺序**

`Session` 类型补充字段：`failedIds: string[]`（本次会话内记过未通过的词 id）。

### 2. 记忆环节主流程

画布清空（所有已出现的词隐藏），然后**串行**逐个出现（同一时刻屏幕上只有一个词）：

**位置**：
- `settings.memorize.position === 'origin'` → 出现在该词**背诵阶段的原始落点**
- `settings.memorize.position === 'centerTop'`（默认）→ 居中偏上，垂直位置 = `memorize.offsetY`（默认 0.3，即距顶部 30%）
- 出现时自动朗读英文

**作答区**（单词旁边或下方，跟随单词位置）：
- 只显示英文（大号）
- 下方按 `activeSenses().length` 生成**对应数量**的输入框，每个框前有淡灰占位提示「义项 1」「义项 2」…
- 输入框横向排列（义项多时自动换行）
- 「提交」按钮 + Enter 提交（最后一个框按 Enter 也提交）

**判分**（`core/model.ts` 的 `senseMatch`）：
- 每个输入框的答案去匹配**任意**一个义项的 `text` 或 `aliases`（顺序无关，答对即可，不要求一一对应）
- 所有框都命中 → 通过
- 有任一个框没命中，或有框为空 → **未通过**

**未通过处理**：
- `failCountTotal += 1`
- 若 `failCount < failCountCap`（默认 2）→ `failCount += 1`
- 加入 `session.failedIds`
- **注意**：达到上限后仍要记 `failCountTotal`、仍加入 `failedIds`（仍会必抽），只是 `failCount` 不再涨

**通用作答闭环**（记忆和拼写环节都必须遵守）：
```
提交 → 立刻弹出「正确答案单词卡」→ 点击卡片任意处 → 卡片消失 → 进入下一个
```
答案卡内容：英文 + 音标 + **全部义项**（含你的输入对照：对的标绿、错的标红并显示正确答案）+ 例句 + 🔊 重读按钮。卡片上明确写着「点击任意处继续」。

**计数与结束条件**：
- 每走完一个词（含看答案卡），`session.memorizeCount[id] += 1`
- 该词计入 `shownIds`
- 一轮抽的词全部走完 → 回到白纸模式，顶部工具条重新出现
- **「结束」按钮变红的条件**（两个都要满足）：
  1. `shownIds.length === wordIds.length`（所有单词都出现过）
  2. 每个词 `memorizeCount[id] >= memorizeTargetCount`（默认 3，不论通过与否）
- 未满足条件时「结束」为灰色（**仍可点击**，点了就是中途退出）

**可无限点记忆**：不点结束就可以一直点「记忆」，不受次数限制。

### 3. 拼写环节

**触发**：当一轮「记忆」抽出的词**全部走完**（最后一个答案卡被点掉）之后，检查本轮抽中的词里有没有 `needSpell === true` 的，有则**自动进入拼写环节**（无需额外点击）。

**形式**：
- 回到白纸画布
- 在**该词背诵阶段的原始落点**上（若该词还没在白纸出现过，则居中偏上），显示它的**全部中文意思**（义项文本 + aliases，逗号分隔）
- 旁边一个输入框，提示「拼写英文」，Enter 提交
- 一个「看提示」按钮：点一次显示首字母（如 `a_____`），再点显示前 3 个字母，**点过提示就算未通过**（记录到本次结果里）

**判分**：忽略大小写和首尾空格，完全匹配 `en` 才算对。
- 错 → 未通过，走同一套计数规则（`failCountTotal += 1`、`failCount` 封顶、加入 `failedIds`）
- 对 → 通过

**闭环**：提交 → 弹出答案单词卡（英文 + 音标 + 义项 + 例句）→ 点击卡片 → 进入下一个拼写词。

**结束**：所有拼写词走完 → 回到白纸模式 + Toast「本轮已完成，可继续点『记忆』或结束」。

### 4. 中途退出

点「结束」（灰色状态）或直接关闭/返回：
- **只写 `session.wordIds`**（`dao.session.saveSession`）
- `placements` / `shownIds` / `memorizeCount` / `failedIds` / 未通过次数 **一律不写回词库**
- Toast 提示「已保存本次词单，进度不保留」

**正常结束**（红色按钮）：
- 除 wordIds 外，把本次累计的 `failCountTotal` / `failCount` 写回词库（这两个是属性，属于真实学习结果）
- 所有词 `status = 'learned'`，分配 `learnOrder`（取当前最大 learnOrder + 1 递增），`learnedAt = now`
- `dao.session.clearSession()`
- 回首页 + Toast「本轮完成，已标记 N 个词为已背」

> 注意区分：中途退出丢的是「本轮进度」，正常结束保留的是「未通过次数这类属性」。这两句话要在代码注释里写清楚。

### 5. 顶部工具条（记忆模式下）

- 「已记忆 x/y」进度
- 「记忆」按钮（继续下一轮）
- 「结束」按钮（灰/红两态，红态时文案「结束本轮」）
- 「返回白纸」（回到背诵模式，已出现的词重新显示出来）

## 验收标准

1. `npx tsc --noEmit` 零报错，`npm run build` 通过
2. 20 个词只出现 5 个时点「记忆」→ 最多抽 10 个，优先未出现的；再点一次继续抽
3. 故意答错 2 个 → 下一轮「记忆」这两个**必定被抽中**（即使超过 10 个上限也要抽到）
4. 未通过 3 次 → 列表页 `failCount` 显示 2（封顶），但 `failCountTotal` 显示 3
5. 提交后答案卡立刻出现，点一下才进下一个（不会自动跳过）
6. 近义词算通过：义项 `text:"v. 放弃"`、`aliases:["抛弃","遗弃"]`，输入「遗弃」判对
7. 给某个词点「拼」→ 本轮记忆走完后自动出现拼写环节，显示中文意思要求填英文，填错记一次未通过
8. 满足「全部出现 + 每词记忆 3 次」后结束按钮由灰变红
9. 中途退出后重新进入背诵 → 只剩词单，进度清零；列表页看未通过次数**没有**增加
10. 正常结束后列表页能看到 N 个词变「已背」、`learnOrder` 有值、未通过次数已写入
