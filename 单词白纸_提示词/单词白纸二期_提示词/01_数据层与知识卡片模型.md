### 2. `src/core/kcModel.ts`

```ts
export function createEmptyCard(title: string): KnowledgeCard;
export function createBlock(type: BlockType): Block;
export function validateCard(c: KnowledgeCard): string[];   // 空数组 = 合法
export function validateBlock(b: Block): string[];

/** 综合掌握程度（主提示词 4.3 的公式） */
export function calcMastery(
  selfScore: number | null,
  examScore: number | null,
  cfg?: { w1?: number; w2?: number; penalty?: number }
): number;

/** 归一化：1~3 → 0~1 */
export function normalizeScore(score: number | null): number;
```

**`calcMastery` 要求**：
- 默认 `w1=0.6`（自评权重高）、`w2=0.4`、`penalty=0.8`
- 公式：`w1*selfNorm + w2*examNorm - penalty*|selfNorm - examNorm|`
- 结果**钳制到 [0,1]**，保留 3 位小数
- 任一分数为 null 时：只有自评 → 直接用自评归一化值；只有考核 → 用考核值；都为 null → 返回 0
- 写注释说明"为什么自评权重更高"（主观题 AI 评分不一定准）和"惩罚项的作用"（抓盲目自信）

### 7. `src/core/blockRender.ts` —— 安全渲染（重点）

```ts
export function renderBlock(b: Block): HTMLElement;
export function renderBlocks(blocks: Block[]): DocumentFragment;
```

**安全铁律**：
- **严禁 `innerHTML` 拼接 AI 输出**。所有文本走 `textContent` 或 `document.createTextNode`
- 每个 BlockType 有确定的渲染结构：
  - `heading` → `<h3>` 级别小标题
  - `text` / `quote` / `tip` → `<p>`（tip 加特殊样式，如黄色左边框）
  - `example` → 英文例句 + 下方小字翻译 + 可选 note
  - `list` → `<ul>` / `<ol>`，`items` 每项一个 `<li>`，文本用 `textContent`
  - `table` → `<table>`，`rows[0]` 作表头
  - `code` → `<pre><code>`，文本用 `textContent`（`lang` 只作 CSS class，用于将来高亮）
- 对未知/损坏的 Block：降级渲染为纯文本，**不要抛异常、不要白屏**
- 写一个 `sanitizeText(s: string): string` 工具：去除控制字符、限制长度（如单块 ≤ 5000 字）
