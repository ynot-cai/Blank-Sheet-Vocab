## 任务

### 1. 每日语境词机制（`src/dao/contextWords.ts` + `api/context-words.ts`）

**规则（用户明确要求）**：
- 每天 **5 个**语境词，**互不相关甚至可以完全不同**（防 AI 硬凑）
- 每道题目**只与其中某一个词关联**
- **生成词时**：检索近 **1 个月**历史，避免重复
- **出题时**：检索近 **3 天**历史题目，避免重复
- **自然日**更新（过零点换新）
- **AI 生成 → 用户确认或修改后才生效**

```ts
export async function getTodayWords(): Promise<DailyContextWords | null>;
export async function generateTodayWords(cfg: AiConfig): Promise<string[]>;  // AI 生成，检索近30天
export async function confirmTodayWords(words: string[]): Promise<void>;     // 用户确认/修改
```

**AI 生成提示词要点**：
- "生成 5 个英语学习语境词/短语，彼此主题完全不相关（如一个食物、一个科技、一个天气…）"
- "避免与以下近期已用过的词重复：[近30天列表]"
- "输出严格 JSON：`{ "words": ["...","...","...","...","..."] }`"
- 可结合日期给建议（如临近节日给相关词）

**UI**：二期首页顶部显示今日语境词，5 个 chip + 「重新生成」「编辑」按钮。
未确认时显示黄条「今日语境词待确认」。

### 2. 出题（`IMPORT_PROMPT` 之外的 `EXAM_PROMPT`）

```ts
export async function generateQuestion(
  card: KnowledgeCard,
  type: string,               // 从 card.examTags 里随机抽一个
  contextWords: string[],     // 今日 5 个词
  recentQuestions: string[],  // 近 3 天历史题目（防重复）
  bankSamples: BankQuestion[],// 参考题库样题（随机 3~5 条同题型）
  cfg: AiConfig
): Promise<{ question: string; contextWord: string; expected?: string }>;
```

**提示词要点**：
- "为知识点【{card.title}】出一道【{typeName}】题"
- "题目需与语境词【{contextWord}】有关联（自然融入即可，不必强行）"
- "从以下 5 个语境词中选**最贴切的一个**来关联，输出你选了哪个"
- "**避免**与以下近期题目重复或雷同：[recentQuestions]"
- "参考以下样题的风格、难度和表述方式：\n{bankSamples}"
- 输出严格 JSON：`{ "question": "...", "contextWord": "...", "expected": "参考答案" }`

**题型特定要求**：
| 题型 | 特殊要求 |
|---|---|
| `fill` 语法填空 | 明确标出提示词（如括号里的原词）和挖空处（用 `____`） |
| `sentence` 独立写句子 | 给明确要求（如"用定语从句写一句关于…的话"） |
| `choice` 选择题 | 4 个选项 A/B/C/D，标注正确答案 |
| `judge` 判断正误 | 给一个句子，判断对错并说明理由 |

### 3. 评分（`GRADE_PROMPT`）—— rubric 化

```ts
export async function gradeAnswer(
  question: string,
  type: string,
  userAnswer: string,
  cfg: AiConfig
): Promise<{ score: 1|2|3; reason: string }>;
```

**每种题型一份 rubric**（写进提示词）：

| 题型 | 评分标准（3 分制） |
|---|---|
| `fill` | 3=完全正确；2=词根对但形式错；1=错误 |
| `choice` | 3=对；1=错 |
| `judge` | 3=判断对且理由对；2=判断对理由错；1=判断错 |
| `sentence` | **3 分项拆解**：语法正确(1) + 用对目标结构(1) + 语义通顺(1) → 3 分全得=3分，得2项=2分，≤1项=1分 |

**提示词硬性要求**：
- "严格按 rubric 打分，输出严格 JSON：`{ "score": <1|2|3>, "reason": "..." }`"
- "`reason` 要具体说明扣分点，让用户知道哪里错了"
- 主观题（sentence）的 reason 必须**逐项列出三项得分情况**

### 5. 题目流程串联

```
过完所有卡片 → 逐题作答
  每道题目：
    1. 从 card.examTags 随机抽一种题型
    2. 从今日 5 个语境词里让 AI 挑最贴切的关联
    3. 查近 3 天历史题目（防重复）
    4. 抽 3~5 条同题型题库样题作参考
    5. AI 出题 → 展示 → 用户作答 → AI 评分 → 展示结果
    6. 记录 ExamRecord（cardId/type/question/userAnswer/aiScore/aiReason/contextWord/date）
  全部答完 → 更新 card.attrs.lastExamScore、重算 mastery、status='learned'
```

**出题量**：按 `card.examLoad.types` 决定出几道（如 fill+choice = 2 道）。总耗时控制在 3~5 分钟。
**每一步都有「保存并退出」**（右上角）。

## 验收标准

1. `npx tsc --noEmit` 零报错，`npm run build` 通过
2. **语境词**：首页生成 5 个词 → 互不相关 → 确认后生效 → 第二天自动换新
3. **防重复验证**：
   - 连续两天生成语境词 → 第二天不会重复第一天的（检索 30 天生效）
   - 同一知识点连续出 3 次题 → 题目内容明显不同（检索 3 天历史生效）
4. **四种题型都能出、能答、能评分**（逐一验证）
5. **rubric 验证**：故意写错答案 → 评分低且 reason 说明具体错在哪；写对 → 3 分
6. **主观题验证**：写一句正确的定语从句 → 3 分；语法对但结构错 → 2 分，reason 逐项列出
7. **题库参考验证**：导入 10 道高考语法填空 → 出题时风格明显接近真题（对比有无题库的两次出题）
8. **手动改分**：点击能把 AI 给的 2 分改成 3 分，且记录被更新
9. `mastery` 在评分后被正确重算（用 `calcMastery`），列表页掌握度变化
10. **保存并退出**：做题到一半退出 → 重进能继续
11. 一期功能完好（回归验证）
