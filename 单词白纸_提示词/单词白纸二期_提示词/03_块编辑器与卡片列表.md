## 任务

### 1. `src/ui/components/BlockEditor.ts`

```ts
export function renderBlockEditor(
  blocks: Block[],
  onChange: (next: Block[]) => void,
  opts?: { compact?: boolean }
): HTMLElement;
```

**每条块一行/一块，支持：**

| 操作 | 说明 |
|---|---|
| 编辑内容 | 文本框就地编辑（`text`/`heading`/`tip`/`quote`）；`example` 有英文+翻译两个框；`list` 每项一个输入框，可增删；`table` 用简易网格，可增删行列 |
| **上移 / 下移** | 调整顺序（用按钮，不必实现拖拽） |
| **复制** | 复制一块 |
| **删除** | 删除一块（二次确认，防误删） |
| **插入** | 在任意位置插入新块，从 8 种类型里选 |

**新增块工具条**：固定在编辑器底部，一排按钮：
`＋标题` `＋正文` `＋例句` `＋列表` `＋表格` `＋代码` `＋引用` `＋提示`

**预览切换**：编辑器顶部一个「预览」开关，打开后用 `renderBlocks` 渲染最终效果，关闭回到编辑态。

**要求**：
- 所有输入都是 textarea/input，**不用 contenteditable**（避免粘贴富文本带来脏 HTML）
- 改动实时通过 `onChange` 回调（由调用方决定何时写库，建议防抖 1 秒）
- 移动端：按钮加大、输入框字号 ≥16px（iOS 防放大）

### 2. `src/ui/pages/KcCardEditPage.ts`（卡片编辑页）

布局：
```
标题：[________________] 
摘要：[________________]
考核标签： [fill ×] [choice ×] [＋添加标签 ▾]
出题量：题型 [fill, choice]  预计耗时 [4] 分钟
─────────────────────────────
[块编辑器区域]
─────────────────────────────
[保存]  [取消]  [删除卡片]
```

- 考核标签从 `EXAM_TYPES` 里选（下拉），可多选，每个带 × 删除
- `examLoad.estMinutes` 数字输入，范围 3~5
- 保存 → `dao.kc.updateBlocks` + 标题/标签等一并更新
- 删除 → 二次确认

### 3. `src/ui/pages/KcCardListPage.ts`（卡片列表）

**顶部统计**：总数 / 未学 / 学习中 / 已学 / 已斩（可点击筛选）

**筛选区**：
- 搜索（标题 + 摘要 + 块内容）
- 状态多选
- 考核方式筛选（下拉：全部 / fill / sentence / choice / judge）
- 排序：复习优先度 / 掌握度 / 创建时间 / 标题
- 分页

**列表项（卡片式）**：
```
┌────────────────────────────────────┐
│ 定语从句：关系代词 vs 关系副词        │
│ 一句话摘要…                          │
│ [fill][choice]        掌握度 ●●○ 72% │
│ 上次复习 3 天前 · 复习 2 次           │
│              [编辑] [详情] [⋯]        │
└────────────────────────────────────┘
```

- 掌握度用可视化（进度条或三色点）
- 「⋯」菜单：预览 / 复制 / 斩 / 复活 / 删除
- 点整张卡片 → 进入详情（只读渲染全部块）

**批量操作**（选中 ≥1 时底部滑出）：批量斩 / 批量复活 / 批量加标签 / 批量删除

## 验收标准

1. `npx tsc --noEmit` 零报错，`npm run build` 通过
2. 编辑一张卡片：改标题、加一个 tip 块、把某块上移、删除一块 → 保存后重新打开，改动都在
3. 8 种块类型都能**新建、编辑、保存、正确渲染**（逐一验证）
4. 表格块能增删行列，保存后表格结构正确
5. 列表页：搜索能命中块内容；按考核方式筛选生效；按掌握度排序正确
6. 斩 → 从默认视图消失；切「已斩」能看到并复活
7. **移动端**：手机上编辑器按钮能点、输入框不放大页面
8. **XSS**：在编辑器里输入 `<script>alert(1)</script>` → 保存后渲染为纯文本，不执行
9. 一期功能完好（回归验证）
