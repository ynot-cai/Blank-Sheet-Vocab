# 阶段 06：复习流程（含 5 词桥接）

> 前置：阶段 01~05 已完成。本阶段实现复习，并打通**与一期的唯一桥接**。

---

## 任务

### 1. 复习与学习的区别（用户明确要求）

| 环节 | 学习（阶段 04） | 复习（本阶段） |
|---|---|---|
| 选数量 | ✅ 一样 | ✅ 一样 |
| 看卡片 + 自评 | ✅ 一样 | ✅ 一样 |
| **背单词** | ❌ 无 | ✅ **跳转到一期背单词界面，上限 5 个** |
| 做题 | ✅ 一样 | ✅ 一样 |
| 保存并退出 | ✅ 每步都有 | ✅ 每步都有 |

**完整复习流程**：
```
① 选择过多少个知识点
        ↓
② 看知识卡片（逐张，自评三级 + 斩）   ← 与学习相同
        ↓
③ 【桥接】跳转到一期背单词界面，上限 5 个词
        ↓  （背完才能继续）
④ 做题（AI 出题 + 评分）              ← 与学习相同
        ↓
⑤ 完成 → 更新 lastReviewAt / reviewCount / mastery / reviewPriority
```

### 2. 抽词：按复习优先度

```ts
export function pickForReview(cards: KnowledgeCard[], count: number, settings): string[];
```

- 候选：`status !== 'chopped'` 且 `status !== 'unlearned'`（即学过/学完的）
- 按 `attrs.reviewPriority` **降序**取前 N 个
- 同分时 `lastReviewAt` 升序（更早复习的优先）

**推荐数字**（复用一期风格）：进入时给一个推荐值，按 `reviewPriority` 第 75 百分位算。

### 3. ⭐ 桥接：背 5 个单词（关键，唯一的一二期连接点）

```
二期复习流程 走到「背单词」环节
   ↓
调起一期背单词界面（复用 LearnPage 的组件/逻辑，不要复制一套）
   ↓
词源：一期主词库 dao.words
   - 优先：status === 'unlearned' 的**新词**
   - 没有新词 → 退化为复习旧词（按一期复习优先度取）
   - 上限：settings.kc.reviewWordLimit（默认 5）
   ↓
背完（或用户点「结束」）→ 回到二期流程 → 进入做题
```

**实现要求**：
- **复用一期页面**，通过参数/会话状态区分（如 `session.type='kc-review'`、`session.wordLimit=5`）
- 桥接时明确显示来源提示：「复习间隙 · 背 5 个单词」
- 背完后 Toast「单词完成，继续做题」
- 若一期词库为空 → 跳过此环节并提示「单词库为空，跳过背单词」
- **不要修改一期的核心逻辑**，只是在外层调用

### 4. 会话阶段的保存与恢复

扩展 `KcSession` 的 `stage` 字段：`'cards' | 'words' | 'exam' | 'done'`

| stage | 含义 | 恢复时 |
|---|---|---|
| `cards` | 正在看卡片 | 从当前第 N 张继续 |
| `words` | 正在背单词（桥接中） | 重新调起背单词 |
| `exam` | 正在做题 | 从当前第 M 题继续 |
| `done` | 完成 | — |

**每一步右上角都有「保存并退出」**（用户明确要求），保存：
- `cardIds` / `currentIndex`
- `selfScores` / `examScores`
- `stage`（含 words 阶段的进度）
- 背单词的 wordIds（若在 words 阶段）

### 5. 完成复习

所有环节走完 → 对每张卡片：
- `attrs.lastReviewAt = now`
- `attrs.reviewCount += 1`
- 重算 `mastery`（用最后一次 self + exam）
- 重算 `reviewPriority`
- `status` 保持 `learned`
- 写库 + 同步

显示本次小结：「复习 8 个知识点，平均掌握度 72%，其中 2 个需要重点回顾」

## 验收标准

1. `npx tsc --noEmit` 零报错，`npm run build` 通过
2. 空库点复习 → 提示「还没有学过的知识点」，不崩
3. 有 10 张已学卡片 → 点复习 → 给出推荐数字 → 输入 8 → 进入
4. **流程顺序验证**（重点）：看卡片 → 自评 → **自动跳到背单词** → 背完 → **自动进入做题** → 完成
5. **背单词上限验证**：桥接时最多只能背 5 个词（第 6 个不会出现）
6. **词源验证**：
   - 一期有新词 → 背的是新词
   - 一期无新词 → 背的是旧词复习
   - 一期词库为空 → 跳过此环节并有提示
7. **保存并退出**（三个 stage 都要验）：
   - 看卡片中途退出 → 重进从该张继续
   - 背单词中途退出 → 重进仍在背单词环节
   - 做题中途退出 → 重进从该题继续
8. 完成后列表页：`距上次复习` 变「今天」、复习次数 +1、掌握度已更新
9. **一期功能完好**（重点回归：桥接调用没有破坏一期的背单词逻辑）
10. 移动端：三个环节的按钮都够大能点
