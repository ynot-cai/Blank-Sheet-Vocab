# 二期怎么用这套提示词（先读这页）

## 核心原则

**每个阶段开一次新对话。** 二期比一期更复杂（涉及 AI 出题评分、块编辑器、与一期桥接），更不可能一次生成完。

## 标准流程

1. 确保一期已完成且能正常运行（**重要前提**）
2. 开新对话 → 粘贴 `00_二期主提示词_每次必贴.md` 全文 → 再粘贴 `0X_某某.md` 全文 → 发送
3. AI 写完 → 你按该阶段末尾的「验收标准」逐条验证
4. 有问题就**在同一对话里**让它改，改到全绿
5. **每阶段结束做一次一期回归**（阶段 01/06 尤其重要，这两个动了一期相关逻辑）
6. 提交一次 git commit
7. 开新对话 → 再贴 00 + 下一阶段 → 循环

> 每次都贴 00 是必须的。它锁死了技术栈、数据模型、块模型、mastery 公式和分层约束。

## 阶段顺序（有依赖，别跳）

```
01 数据层 + 安全块渲染     ← 地基，且最容易破坏一期，做完必须回归
02 聊天式录入             ← 没卡片就没法测后面
03 块编辑器 + 卡片列表     ← 让卡片可改可管
04 学习流程               ← 核心体验
05 出题与评分             ← 技术含量最高（语境词 + rubric + 题库）
06 复习流程 + 5词桥接     ← 打通一二期，必须回归一期
07 优先度设置 + 题库管理   ← 收尾
```

## 几个重点提醒

- **阶段 01 做完一定要验证一期没坏**（背诵、记忆、复习、列表、同步全试一遍）。它改了数据层，是最高风险阶段。
- **阶段 05 最容易出偏差**：语境词防重复、rubric 评分、题库参考三件事，验收时要重点盯。
- **阶段 06 的桥接是唯一碰一期逻辑的地方**：要求 dsh 用"复用"而不是"复制"，且背完单词后必须回到二期流程。
- **AI 相关功能没填密钥也能测**：会走规则降级或直接报错，不影响验证其他部分。

## 关于题库（阶段 05/07）

用户明确要求保留「添加题库」按钮，但**不追求大而全**：
- 每个题型 30~50 道高质量样题就够
- 题库只作风格参考，不会原样出题
- 推荐来源：高考真题语法填空、English Grammar in Use、CC BY-NC 授权数据集
- **版权提醒**：仅供个人学习，勿分发或商用

详见 `../二期工程需求梳理.md` 第 6 节。

## 已知限制（提前知道，别到时候觉得是 bug）

- AI 出题质量取决于模型能力和提示词，需要迭代调整
- 主观题（独立写句子）AI 评分可能不稳定 —— 这是为什么默认自评权重（0.6）高于考核权重（0.4）
- 每日语境词需要用户确认才生效（这是设计，不是缺陷）
- 一期二期数据隔离，唯一桥接点是"复习时背 5 个单词"
- 块编辑器用 input/textarea 而非 contenteditable，不支持富文本粘贴（防止脏 HTML）
