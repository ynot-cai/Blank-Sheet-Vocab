## 任务

### 1. 二期设置页 `#/kc/settings`

#### 1.1 综合掌握度（mastery）公式

显示当前公式：
```
mastery = w1 × 自评 + w2 × 考核 − penalty × |自评 − 考核|
```
三个数字输入：`w1`（0.6）/ `w2`（0.4）/ `penalty`（0.8）

下方**解释性说明**（照抄）：
> 自评权重更高（默认 0.6），因为主观题（独立写句子）的 AI 评分不一定准。
> 「不一致惩罚」用于捕捉**盲目自信**：自评"会了"但考核"不会"时，掌握度会被额外拉低，
> 让这类知识点自动被提上来复习。这是最该优先复习的状态。

提供三个预设按钮：
- **默认**（0.6 / 0.4 / 0.8）
- **信任 AI 评分**（0.4 / 0.6 / 0.8）—— 考核权重更高
- **不看不一致**（0.6 / 0.4 / 0）—— 关掉惩罚

「试算」按钮：拿最近 5 次记录算一遍，表格展示（自评/考核/算出的 mastery）

#### 1.2 综合复习优先度

三个属性参与计算：
| # | 属性 | 变量 |
|---|---|---|
| 1 | 距学习天数 | `daysSinceLearned` |
| 2 | 距上次复习天数 | `daysSinceReview` |
| 3 | 综合掌握程度 | `mastery` |

提供**预设 + 自定义表达式**（复用一期 `priority.ts` 的表达式求值机制，含白名单校验）：

预设：
- `balanced` 均衡：`daysSinceReview * 0.5 + (1 - mastery) * 10`
- `weakFirst` 薄弱优先：`(1 - mastery) * 20 - reviewCount`
- `forgetting` 遗忘曲线：`daysSinceReview / (reviewCount + 1) + (1 - mastery) * 8`

自定义 textarea + 变量 chip（点击插入）+ 「试算」+ 语法校验

#### 1.3 其他二期参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `contextWordCount` | 5 | 每日语境词数量 |
| `contextGenLookbackDays` | 30 | 生成词时检索近 N 天避重 |
| `examDedupeLookbackDays` | 3 | 出题时检索近 N 天避重 |
| `reviewWordLimit` | 5 | 复习时背单词上限 |
| `examLoadDefaultMinutes` | 4 | 默认出题耗时 |

#### 1.4 一期桥接设置

- 「复习时背单词上限」数字输入（默认 5）
- 说明：「复习流程中会跳转到背单词界面，词来自一期词库，优先新词」

### 2. 题库管理页 `#/kc/bank`

**布局**：
```
┌────────────────────────────────────┐
│ [＋ 添加题库]       共 128 条       │
│ 筛选：[全部▾] [语法填空▾] [搜索…]   │
├────────────────────────────────────┤
│ ☑ [语法填空] 2023全国甲卷          │
│   题目内容预览…            [详情][删]│
│ ☐ [选择题] English Grammar in Use  │
│   题目内容预览…            [详情][删]│
├────────────────────────────────────┤
│ 已选 1 条  [批量删除] [全部导出]    │
└────────────────────────────────────┘
```

**「添加题库」按钮（用户明确要求保留）**：
- 点击 → 弹窗，两种模式：
  1. **单条添加**：选题型 → 粘贴题目内容 → 填来源标注（如"2023全国甲卷"）
  2. **批量粘贴**：一个文本框，AI 自动按题型分类（调一次 AI 做分类，或按简单规则切分）
- 支持从文件导入（txt/md）
- 导入后列表展示，可删除、搜索、按题型筛选

**说明文案**（照抄）：
> 题库只作为 AI 出题的**风格参考**，不会原样出题。
> 每个题型 30~50 道高质量样题就够，不必追求大而全。
> 注意版权：仅供个人学习使用，请勿分发或商用。
