# 阶段 04：学习流程（选数量 → 看卡片 → 自评三级）

> 前置：阶段 01~03 已完成。本阶段做二期的核心学习体验。

---

## 任务

### 1. 进入流程

点二期首页「学习」→ 弹对话框：
- 数字输入「本次学多少个知识点？」
- 下方提示：「当前未学 N 个，建议 5~10 个」
- 确认 → 开始

**抽词**：`status === 'unlearned'` 的卡片，按 `createdAt` 升序（先录入先学）。数量不足按实际进入并提示。

### 2. 学习主界面

**布局（参考一期的"白纸"简洁感，但不用白纸撒点）**：

```
┌────────────────────────────────────┐
│                                    │
│         [知识卡片内容区]             │
│     （renderBlocks 渲染全部块）      │
│                                    │
│                                    │
├────────────────────────────────────┤
│  进度 3/8                          │
│  [不会]  [模糊]  [会了]      [斩]   │
└────────────────────────────────────┘
```

**卡片区**：
- 顶部：标题（大号）
- 下方：块渲染内容，可滚动
- **角落显示考核标签**（如 `[语法填空][选择题]`）—— 用淡色 chip，位置在卡片右上角

**底部三个按钮 = 掌握程度（自评）**：
| 按钮 | 分值 | 配色建议 |
|---|---|---|
| **不会** | 1 | 红色系 |
| **模糊** | 2 | 黄色系 |
| **会了** | 3 | 绿色系 |

**「斩」按钮**：单独放在右侧，视觉上和自评按钮区分开（如灰色 + 骷髅/剪刀图标）
- 点击二次确认「确定斩掉？斩后不再出现」
- 斩后 `status='chopped'`，卡片从本次流程移除

### 3. 流程控制

```
选数量 → 逐张看卡片 → 每张自评 → 全部过完 → 进入做题（阶段 05）
```

- 点自评按钮 → 记录 `attrs.lastSelfScore` → **自动进入下一张**（不需要额外确认）
- 自评后**立刻写库**（`dao.kc.updateAttrs`）
- 同时更新 `attrs.learnedAt = now`、`status = 'learning'`
- 全部卡片过完 → 提示「卡片看完啦，接下来做几道题」→ 进入做题环节（阶段 05 实现，本阶段先弹占位 Toast）

### 4. 「保存并退出」（必须实现）

**在学习流程的每一步都要能保存退出**（用户明确要求）：

- 位置：右上角「保存并退出」按钮
- 行为：
  - 保存当前**完整进度**：当前是第几张、已自评的分数、卡片列表
  - 存到 `dao.kcSession`（新增一个轻量会话 DAO，本地 IndexedDB + 云端可选）
  - 退出到二期首页
- 重进「学习」时：若检测到未完成的会话 → 询问「继续上次（剩余 N 张）/ 重新开始」

**会话数据结构**：
```ts
interface KcSession {
  id: string;
  type: 'study' | 'review';
  cardIds: string[];
  currentIndex: number;
  selfScores: Record<string, number>;   // cardId → 1|2|3
  examScores: Record<string, number>;   // 阶段 05 用
  stage: 'cards' | 'words' | 'exam' | 'done';   // 复习流程用
  finished: boolean;
  createdAt: number;
  updatedAt: number;
}
```

本阶段只用到 `cardIds` / `currentIndex` / `selfScores` / `stage='cards'`。

### 5. 键盘快捷键

- `1` / `2` / `3` → 对应不会/模糊/会了
- `Enter` → 下一张
- `Esc` → 保存并退出（弹确认）
- 与一期保持一致的手感

## 验收标准

1. `npx tsc --noEmit` 零报错，`npm run build` 通过
2. 选 5 个知识点 → 逐张展示，卡片内容**渲染正确**（表格、列表、例句都正常）
3. 卡片右上角能看到考核标签 chip
4. 点「模糊」→ 自动跳下一张；进度更新；该卡片 `lastSelfScore=2`、`learnedAt` 有值、`status='learning'`
5. 键盘 `1/2/3` 能自评，`Esc` 能退出
6. 「斩」→ 二次确认 → 卡片消失，不再出现；列表页「已斩」能找到并复活
7. **保存并退出**：学到第 3 张退出 → 重进询问「继续上次（剩 5 张）」→ 继续后从第 3 张开始，之前自评的分数还在
8. **移动端**：手机上三个自评按钮够大（≥44px）、能点；卡片内容可滚动
9. 一期功能完好（回归验证）
