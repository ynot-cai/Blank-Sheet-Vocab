## 3. 硬约束（违反即不合格）

1. **不破坏一期**：一期所有功能（背诵/记忆/复习/列表/录入/设置/云同步）必须照常可用。每阶段结束都要验证。
2. **服务器永不接触 AI 密钥**（方案 B）：不得有存储密钥的逻辑，不得有存密钥的表。
3. **只存哈希**：同步码只以 SHA-256 哈希落库（沿用一期 `space_key`）。
4. **空间隔离**：所有二期 SQL 必须带 `WHERE space_key = ?`，DAO 层强制。
5. **本地优先**：所有操作先写 IndexedDB，再后台同步。同步失败只轻提示，**绝不阻断使用**。断网时二期功能（看卡片、自评、做题回放）也要能用。
6. **批量分批**：同步推送每批 ≤ 500 条（Vercel 请求体 4.5MB 限制）。
7. **块模型渲染，不渲染 HTML**：AI 只能输出结构化 Block，**严禁**把 AI 输出当 HTML 插入 DOM（防 XSS）。
8. **TypeScript strict**（不许 `any`）、**零魔法数字**（集中在 `config.ts`）、单文件超 300 行就拆。
9. **不渲染任意 HTML**：AI 输出只能解析为 Block 后按 type 渲染。

## 4. 核心数据模型

### 4.1 块（Block）—— 卡片结构自由的基础

```ts
export type BlockType =
  | 'heading'    // 小标题
  | 'text'       // 正文段落
  | 'example'    // 例句（可带翻译）
  | 'list'       // 列表
  | 'table'      // 表格
  | 'code'       // 代码块
  | 'quote'      // 引用
  | 'tip';       // 提示/易错点

export interface Block {
  id: string;
  type: BlockType;
  content?: string;      // heading / text / tip / quote / code
  translation?: string;  // example 的中文翻译
  items?: string[];      // list
  rows?: string[][];     // table（首行为表头）
  lang?: string;         // code
  note?: string;         // example 的补充说明
}
```

### 4.2 知识卡片（KnowledgeCard）

```ts
export interface KnowledgeCard {
  id: string;
  title: string;              // 知识点标题，如「定语从句：关系代词 vs 关系副词」
  summary: string;            // 一句话摘要
  blocks: Block[];            // 结构自由靠块的任意组合
  examTags: string[];         // 考核方式标签（可多个 = 多种考法）
  examLoad: {                 // 出题量，由录入时 AI 决定
    types: string[];          // 本次建议题型组合
    estMinutes: number;       // 预计耗时，3~5 分钟
  };
  source: { chatId?: string; raw?: string };  // 来源（聊天录入的原始对话）
  attrs: {
    learnedAt: number | null;      // 属性1 首次学习时间
    lastReviewAt: number | null;   // 属性2 上次复习时间
    reviewCount: number;
    lastSelfScore: number | null;  // 最近一次自评（1~3）
    lastExamScore: number | null;  // 最近一次考核（1~3）
    mastery: number;               // 属性3 综合掌握程度（0~1，见 4.3）
    reviewPriority: number;        // 综合复习优先度
  };
  status: 'unlearned' | 'learning' | 'learned' | 'chopped';
  createdAt: number;
  updatedAt: number;
  deleted: number;                // 软删除
}
```

### 4.3 综合掌握程度（mastery）—— 关键算法

**三个自评/考核按钮 = 1/2/3 分（不会=1，模糊=2，会了=3）**

```
normalized  = score / 3                  // 归一化到 0~1
mastery = w1 * selfNorm + w2 * examNorm - penalty * |selfNorm - examNorm|
```

**默认值**：
- `w1 = 0.6`（自评权重更高 —— 用户明确要求，因主观题 AI 评分不一定准）
- `w2 = 0.4`
- `penalty = 0.8`（不一致惩罚）

**为什么加惩罚项**：自评高但考核低 = **盲目自信**（以为会了其实不会），是最危险状态，必须被自动提上来复习。

| 自评 | 考核 | mastery 效果 |
|---|---|---|
| 3 | 3 | 高（真掌握） |
| 3 | 1 | **被惩罚拉低** ⚠️ |
| 1 | 3 | 中等（低估） |
| 1 | 1 | 低（真不会） |

`mastery` 钳制到 `[0, 1]`。默认公式 + 可自定义（设置页，复用一期 `priority.ts` 的表达式机制）。

### 4.4 考核方式标签（可扩展）

```ts
export const EXAM_TYPES = [
  { id: 'fill',      name: '语法填空',  desc: '提示词 + 挖空练习' },
  { id: 'sentence',  name: '独立写句子', desc: '给要求造句（如用定语从句）' },
  { id: 'choice',    name: '选择题',    desc: '' },
  { id: 'judge',     name: '判断正误',  desc: '' },

```
**可扩展**：新增题型只需往这个数组加，不要写死 4 个的分支判断。

### 4.5 每日语境词（防重复）

```ts
export interface DailyContextWords {
  id: string;
  spaceKey: string;
  date: string;          // 'YYYY-MM-DD'，自然日
  words: string[];       // 5 个，互不相关
  source: 'ai' | 'manual';
  confirmed: boolean;    // 用户确认后才生效
  createdAt: number;
}
```

**机制（用户明确要求）**：
- 每天 **5 个**语境词，**互不相关甚至可以完全不同**（防止 AI 硬凑）
- 每道题目**只与其中某一个词关联**（不强求全部关联）
- **生成词时**：检索近 **1 个月**的历史，避免重复
- **出题时**：检索近 **3 天**的历史题目，避免重复
- 自然日更新（过零点换新一组）
- AI 生成 → **用户确认或修改**后才生效

### 4.6 题目历史 & 题库

```ts
export interface ExamRecord {          // 已出过的题（防重复 + 复盘）
  id: string;
  spaceKey: string;

  type: string;          // EXAM_TYPES 的 id
  question: string;
  userAnswer: string;

  id: string;
  spaceKey: string;
  type: string;
  content: string;       // 题目原文（含答案）
  source: string;        // 来源标注，如「2023全国甲卷」
  createdAt: number;
}
```

## 5. Turso 表设计（在一期同一个库里新建）

```sql
CREATE TABLE IF NOT EXISTS knowledge_cards (
  id TEXT PRIMARY KEY,
  space_key TEXT NOT NULL,
  title TEXT NOT NULL,
  summary TEXT,
  blocks TEXT NOT NULL,          -- JSON
  exam_tags TEXT NOT NULL,       -- JSON array
  exam_load TEXT,                -- JSON {types, estMinutes}
  source TEXT,                   -- JSON
  attrs TEXT NOT NULL,           -- JSON
  status TEXT NOT NULL,
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL,
  deleted INTEGER DEFAULT 0
);
CREATE INDEX IF NOT EXISTS idx_kc_space ON knowledge_cards(space_key, updated_at);

CREATE TABLE IF NOT EXISTS daily_context_words (
  id TEXT PRIMARY KEY,
  space_key TEXT NOT NULL,
  date TEXT NOT NULL,            -- 'YYYY-MM-DD'
  words TEXT NOT NULL,           -- JSON array
  source TEXT NOT NULL,
  confirmed INTEGER DEFAULT 0,
  created_at INTEGER NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_dcw ON daily_context_words(space_key, date);

CREATE TABLE IF NOT EXISTS exam_records (
  id TEXT PRIMARY KEY,
  space_key TEXT NOT NULL,
  card_id TEXT NOT NULL,
  date TEXT NOT NULL,
  type TEXT NOT NULL,
  question TEXT NOT NULL,
  user_answer TEXT,
  ai_score INTEGER,
  ai_reason TEXT,
  context_word TEXT,
  created_at INTEGER NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_exam ON exam_records(space_key, created_at);

CREATE TABLE IF NOT EXISTS bank_questions (
  id TEXT PRIMARY KEY,
  space_key TEXT NOT NULL,
  type TEXT NOT NULL,
  content TEXT NOT NULL,
  source TEXT,
  created_at INTEGER NOT NULL,
  deleted INTEGER DEFAULT 0
);
CREATE INDEX IF NOT EXISTS idx_bank ON bank_questions(space_key, type);
```

**注意：没有存 AI 密钥的表。** 这是安全底线。

## 7. 与一期的唯一桥接点（重要）

**复习流程中「背 5 个单词」这一步调起一期背单词界面。**

```
二期复习
  → 看知识卡片（二期数据）
  → 【桥接】调起一期背单词界面，上限 5 个词
       词源：一期主词库（dao.words）
       优先：未背过的新词；没有新词 → 复习旧词
  → 结束后回到二期流程
  → 做题（二期数据）
```

**除此处外两套数据完全独立**：独立表、独立 DAO、独立页面路由。
但**共用同一套同步通道**（同一个 Turso 库、同一个 spaceKey 隔离逻辑）。
