### 5. `src/core/model.ts`

```ts
export function createSense(text: string, aliases?: string[]): Sense;
export function createWord(en: string, senses: Sense[], sourceId: string): Word;
export function normalizeEn(en: string): string;   // trim + 去首尾标点 + 保持原大小写，返回用于去重的 key
```

`senseMatch` 要求：忽略大小写、忽略所有空白和常见标点（`.,，。；;、/`），命中 `text` 或任一 `aliases` 即算通过。

### 6. `src/core/priority.ts`

```ts
export const PRESETS: Record<PriorityPreset, { name: string; desc: string; expr: string }>;
export function evalPriority(expr: string, w: Word, now?: number): number;
export function computePriority(w: Word, settings: Settings, now?: number): number;
```

可用变量（作用域内注入）：`needSpell`(0/1)、`failCount`、`failCountTotal`、`reviewCount`、`daysSinceReview`（无记录时给 999）、`daysSinceLearned`。

- 三个预设表达式写死在 `PRESETS` 里：
  - `forgetting` 遗忘曲线型：`daysSinceReview / (reviewCount + 1) + failCount * 2`
  - `failFirst` 未通过优先型：`failCount * 10 + daysSinceReview`
  - `balanced` 均衡型：`daysSinceReview * 0.5 + failCount * 3 + (needSpell ? 2 : 0) + reviewCount * -0.2`
- `evalPriority` 用 `new Function` 求值，**必须 try/catch**，异常时返回 0 并 console.warn
- 表达式只允许数字运算，求值前用正则白名单校验（只允许 `0-9 . + - * / ( ) ? : < > = ! & | needSpell failCount failCountTotal reviewCount daysSinceReview daysSinceLearned true false 空格`），不通过直接返回 0
