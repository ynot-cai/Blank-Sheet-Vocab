# 阶段 07：复习页

> 前置：阶段 01~06 已完成，背诵 + 记忆 + 拼写全链路可用。

## 任务

### 1. `src/ui/pages/ReviewPage.ts`

**进入流程**：主界面点「复习」→ 弹对话框：

- 数字输入「本次复习多少个词？」
- 输入框下方一行**推荐值提示**：
  「按当前优先度，建议复习 **N** 个（优先度 ≥ X 的词共 N 个）」
  旁边一个「用推荐值」按钮，点了就填进输入框
- 推荐值算法（写在 `src/core/pick.ts`）：
  ```ts
  export function recommendReviewCount(words: Word[], settings: Settings, now?: number): { count: number; threshold: number };
  ```
  - 候选 = `status !== 'chopped'` 且 `status !== 'unlearned'` 的词（即学过 / 学完的）
  - 算每个词的 `reviewPriority`，取第 75 百分位作为 `threshold`
  - `count` = 优先度 ≥ threshold 的词数，`clamp` 到 `[1, reviewGroupSize * 3]`
  - 词库为空或全未背时返回 `{ count: 0, threshold: 0 }`，页面提示「还没有已背的单词，先去背一轮吧」
- 确认后进入分组流程

**抽词**：候选按 `reviewPriority` 降序取前 N 个（N = 用户输入或推荐值）。

**分组**：
```ts
export function groupWords(ids: string[], size: number): string[][];
```
- 每组不超过 `reviewGroupSize`（默认 30），最后一组可以少
- 分组时**不要**把优先度接近的词全塞一组，按优先度降序后蛇形分配（第 1 组拿 1、2n、2n+1…，保证每组优先度分布均匀）—— 实现简单的话直接顺序切分也行，但要在注释里说明选择了哪种及原因

**每组流程**：
- 组间有个「第 k/m 组」指示
- **每一组完整走一遍与「背诵」相同的流程**：白纸撒词 → 下一个 → 悬停标识 → 单词卡（编辑/拼/斩）→ 记忆 → 拼写环节 → 结束
- 代码上**复用 `LearnPage` 和 `MemorizePage`**，通过 session 的 `type: 'review'` 和 `groupId` 区分，不要复制一套
- 一组结束后 → 弹「第 k 组完成，继续下一组 / 休息一下」→ 继续则进入下一组，休息则保存剩余组进度（只存 wordIds + 当前组号）后回首页

**复习完成**（走完所有组且点正常结束）：
- `lastReviewAt = now`
- `reviewCount += 1`
- `learnedAt` 不变
- `status` 保持 `learned`
- 重算 `reviewPriority`

**复习中途斩词**：该词从当前组和后续组移除，组内数量相应减少。

### 2. `src/core/pick.ts` 补充

```ts
export function pickForReview(words: Word[], count: number, settings: Settings, now?: number): string[];
```
- 排除 `chopped` 和 `unlearned`
- 按 `reviewPriority` 降序、`lastReviewAt` 升序（同分时更早复习的优先）
- 取前 `count` 个

### 3. 会话类型扩展

`Session` 增加字段：
```ts
groupId: number;        // 当前第几组（0-based），learn 类型恒为 0
groups: string[][];     // 所有分组，仅内存
```
`dao.session.saveSession` 仍然**只持久化**：`id` / `type` / `wordIds`（合并后的全量）/ `groupId` / `finished` / `createdAt`。

### 4. 首页未完成时

若 `dao.session.loadSession()` 有未完成的会话，首页在「背诵」/「复习」按钮上显示一个小角标「上次未完成：N 词」，点击后询问「继续上次 / 重新开始」：
- 继续 → 用保存的 `wordIds` 重新进入（落点重新随机生成）
- 重新开始 → `clearSession()` 后走正常流程

### 5. `App.ts` 收尾

6 个按钮全部点亮：录入 / 背诵 / 记忆 / 复习 / 单词列表 / 设置。
其中「记忆」按钮：若当前无 session，Toast「请先开始一轮背诵」，否则直接进入记忆模式。

## 验收标准

1. `npx tsc --noEmit` 零报错，`npm run build` 通过
2. 空库点复习 → 提示先去背单词，不崩
3. 有 50 个已背词时点复习 → 给出推荐数字，点「用推荐值」能填入
4. 输入 65 个 → 分成 3 组（30/30/5）
5. 第 1 组走完 → 提示继续下一组 → 继续后进入第 2 组，流程与背诵一致（白纸/朗读/卡片/记忆/拼写都能用）
6. 复习中途斩词 → 该词从后续组消失
7. 全部组完成 → 列表页看到这些词 `reviewCount + 1`、`距上次复习` 变为「今天」
8. 中途休息退出 → 首页显示角标，点继续能接着第 N 组开始
9. 切换设置页的优先度预设 → 重算优先度 → 复习推荐数字发生变化
